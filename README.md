# 《熄燈號之後》AFTER TAPS

> 專案代號：**DOOM**　｜　3D 開放式末日生存・1–4 人合作・知識鎖異能・敘事導演

**一句話**：世界撞上了另一個世界。半數人類醒來時多了一種無法解釋的力量——但沒有人告訴你那是什麼。你是警校生，蟲潮正從天空的裂縫湧進來，你有七十二小時。

---

## 規格速覽

| 項目 | 內容 |
|---|---|
| 類型 | 3D 開放式末日生存／合作動作冒險／Roguelite 敘事 |
| 視角 | 第三人稱肩後（瞄準時可切第一人稱） |
| 人數 | 單人（AI 同學小隊）或 1–4 人連線合作，選配「寄生者協議」社交推理模式 |
| 單局長度 | 約 2.5–3 小時，涵蓋遊戲內「黃金七十二小時」，可中途存檔 |
| 舞台 | 去識別化的警察大學「國立鷹嶺警官學院」＋周邊「雲台鎮」 |
| 每局變化 | 種子決定開局日、天氣、裂隙位置、同學命運、啟動的校園傳說、Boss、每個人的異能 |
| 目標平台 | PC（Steam）優先，主機版第二階段 |
| 建議引擎 | Unreal Engine 5（Gameplay Ability System＋Mass Entity 蟲群） |
| 分級建議 | 15+（緊張、驚悚，血腥程度可調；提供「蟲恐懼友善模式」） |

## 五大設計支柱

1. **未知的自己**：異能是知識鎖，不靠經驗值解鎖。你知道怎麼用，它就能用；你不知道，它就一直沉睡。
2. **警察的方式**：系別即職能。盾陣、破門、後送傷患、雙鑰械彈庫、鑑識採證、查驗身分——用警察的專業活下去，也守住警察的倫理。
3. **每一局都是一條新時間線**：主線骨架固定、血肉隨機。同一群人、同一座校園，命運每次不同。
4. **活下來，也讓別人活下來**：救下的同學就是你的「接續者」，也會讓蟲巢少一份養分。
5. **像小說一樣被記住**：章回標題、定格句、營火夜話、無線電劇場，最後由一份結算報告把這條時間線寫成故事。
