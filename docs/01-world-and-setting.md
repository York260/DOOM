# 01　世界觀與舞台

## 1. 世界觀總覽

### 1.1 疊界：日常被打破的那一刻

某一天早上（日期與時刻由時間線種子決定，預設為 **07:42**），地球與另一個世界「**蒼淵**」發生了第一次疊合。

- **交融波**：一道無聲的波從裂隙擴散出去，所有人同時聽見一個極低的音。時鐘停止、電子設備短暫失靈、天空像宣紙浸到墨一樣暈開。
- **覺醒**：受波及的人類大約半數昏迷，醒來時多了一種「無法用科學解釋」的能力，稱為**異能**，擁有異能的人稱為**覺醒者**；其餘的人稱為**常人**，身上沒有任何變化。
- **異變**：動物、植物，甚至物品，都會受到不同程度的影響（見 `04`）。
- **裂隙**：天空、地面、水面出現數道「傷口」，也就是次元通道。蟲族「**蝕群**」從裂隙中湧出。

### 1.2 蒼淵：正在沉沒的異獸世界

- 蒼淵是一個有兩顆月亮、植物高達百米、充滿巨獸的世界，風格近似《山海經》的想像，但生物都是原創或改編的。
- 蒼淵已經被蝕群吞噬殆盡。它是一個正在「沉沒」的世界，像垂死的星體一樣朝地球墜落，疊界就是它撞上地球的過程。
- 蒼淵的亡獸死後，牠們的「**天賦**」散落四方，尋找新的宿主，於是半數人類覺醒。**每一個異能，都是某隻已死的蒼淵異獸的最後一口氣。**這就是異能的「真名」（見 `02`）。
- 倖存的蒼淵異獸跟著穿過裂隙逃到地球，牠們是難民，不是侵略者。

### 1.3 蝕群：會學習的飢餓

- 一個沒有個體意志、由「**群思**」統合的蟲族。
- 牠們需要**生物量**來擴張裂隙。牠們會把活體拖回「**繭池**」，轉化成養分和新的蟲。
- 群思並非全然無知。它是由**所有被吞噬的生命的聲音**所組成的合唱。它會學習、會模仿，也會評價。
- 牠們不憎恨人類，只是把人類看成「**溫血碎片**」，就像人類看待一片可以開墾的森林。

### 1.4 交融法則（世界的新規則，也是遊戲規則）

| 法則 | 內容 | 遊戲意義 |
|---|---|---|
| 一、天賦擇主 | 異能並非隨機落下，而是和宿主的性格與經歷有微弱的共振 | 異能生成時會參考玩家的系別與背景特質，加權但不決定結果 |
| 二、生命改寫 | 越接近蒼淵生物形態的地球生物，越早、越劇烈異變 | 狗、烏鴉、錦鯉、榕樹各有不同的異變方向 |
| 三、意念放大 | 被大量人類「相信」或「使用」的物品與地點會產生異常性質 | 警徽、校鐘、國旗、老兵的刀成為異化物；校園七大不可思議成真 |
| 四、疊合加深 | 全球「疊合率」從 0% 升到 100%，物理規則逐漸蒼淵化 | 後期會出現重力潮汐、時間雨、孢子霧；異能更強，代價也更重 |
| 五、口徑定律 | 裂隙越寬，能穿過的生物越大；裂隙靠生物量擴張 | 難度隨世界邏輯分階段提升；玩家可以藉由減少生物量來拖慢它 |
| 六、蒼淵之敵 | 蒼淵的植物與異獸，幾億年來都在對抗蝕群 | 蒼淵植物有驅蟲成分，可以栽種；異獸可以成為盟友 |

### 1.5 真相層（僅供編劇；跨局逐步揭露，見 `08` 零號時間線）

> 以下內容玩家不會在單局中完整得知，要靠跨局的殘響碎片慢慢拼湊。

1. **鷹嘴台地是一個「薄點」**：兩個世界在這裡的距離最近，每隔約五十年就會發生一次小疊合。
2. **1972 年的小疊合**：當年的裂隙很小，只有針孔大小，被一群警校生用某種方式封住了。他們的名字沒有被記錄下來。
3. **學院為何建在這裡**：鷹嶺警官學院的前身是一座「守望所」，學院的建立是為了看守這個薄點。校史館裡的「**黑鐵印**」是當年的封印核心。
4. **熄燈號是封印儀式**：熄燈號的旋律由當年的守望者寫成，每天晚上在薄點上播放，用來「撫平」兩個世界之間的振動。這個傳統一直流傳到今天，只是沒有人記得原因。在這一次疊界中，有人在三天前停掉了熄燈號的廣播（這是一個每局可能不同的謎團：是誰？為什麼？）。
5. **忠勇牆上空白的七格**：校史館的殉職紀念牆上，有七個從來沒有刻上名字的空格。祕密結局中，玩家們的名字會出現在那裡，因為時間在薄點上是一個圓。
6. **群思的本質**：蝕群可能是蒼淵某個古老文明為了對抗「更外面的東西」而造出的武器，後來失控了。這一點刻意保留開放，留給續作。

## 2. 舞台：國立鷹嶺警官學院

### 2.1 去識別化原則

- 校名、地名、人名全部虛構。配置參考一般警察大學常見的設施組合（射擊館、械彈庫、鑑識實驗室、消防訓練場、水上訓練池、駕訓場、警犬訓練區、學生大隊宿舍），但經過重新排列，不對應任何真實校園的平面圖。
- 不出現真實人物、真實校徽與真實校訓。
- 制度細節（學生隊編制、值星、內務、站哨、點名、熄燈號）採用通用的警校／軍校文化，不指涉特定學校。

### 2.2 地理

- **雲台市・鷹嘴台地**：學院位於台地邊緣，三面是陡坡，可以俯瞰下方的盆地城市，遠方是「國門國際機場」的跑道燈。
- 台地邊緣的地形本身就是戰術元素：懸崖、坡地、排水涵洞、舊防空洞。蟲群從坡下往上湧的畫面是本作的招牌鏡頭之一。
- 校區約 60 公頃，加上周邊的「雲台鎮」，開放世界總面積約 3.5 km²（⚙ 依 Q1）。

### 2.5 地圖設計原則

- **垂直性**：屋頂、天橋、水塔、地下管線層、防空洞、排水涵洞，蟲會從上下兩個方向來，玩家也可以。
- **動態地形**：巢苔擴散、建築坍塌、異界植物生長、重力潮汐。同一條路在第一天和第三天完全不一樣。
- **安全感會反轉**：第一天最安全的宿舍地下室，第三天會被穿岩成蟲從下方打通。
- **地標可辨識**：鐘樓、水塔、至善堂的屋頂、田徑場上空的裂隙，從校園任何地方都看得到，方便多人報位置：「我在鐘樓西邊！」

## 4. 角色

### 4.1 玩家角色

每位玩家開局時選擇**系別**與**年級**，再由系統隨機抽兩項**背景特質**。異能則是完全隱藏的。

#### 系別（十系，初始開放六系，其餘透過成就解鎖）

| 系別 | 專長（被動） | 專屬工具 | 末日中的定位 |
|---|---|---|---|
| 刑事系 | 「現場直覺」：可以看見拖行痕跡、血跡、足跡，追蹤被擄走的人 | 刑事蒐證箱 | 救援追蹤 |
| 鑑識系 | 「採證」：解剖蟲屍的速度加倍，異能徵兆描述更精確 | 採證工具組、紫外燈 | 情報與研究 |
| 消防系 | 「火場」：可使用空氣呼吸器（免疫孢子霧），擅長控火與破拆 | 消防斧、空氣呼吸器 | 開路、救助、焚巢 |
| 水上警察系 | 「水域」：長時間潛水、駕駛小艇、水中戰鬥 | 潛水裝備 | 水路、鏡湖與游泳池路線 |
| 資訊系 | 「駭入」：控制監視器、電子門、無人機，掃描無線電頻率 | 筆電、無人機 | 偵察與控制 |
| 交通系 | 「駕駛」：所有載具上手、路線規劃、快速架設拒馬 | 交通錐與拒馬組 | 機動與撤離 |
| 國境警察系 | 「查驗」：身分查驗小遊戲，可以辨識擬態蟲與被寄生者 | 證件查驗燈 | 反滲透 |
| 外事系 | 「語言」：解碼蟲語與異獸語的速度加倍，擅長談判 | 錄音筆 | 溝通與對話結局 |

### 4.3 NPC 共通系統

- **隱藏異能**：每位 NPC 也有自己的隱藏異能（或者是常人），玩家可以透過觀察與對話幫他們發現，被發現的異能才能在戰鬥中使用。
- **四項內在值**：信任（對玩家）、恐懼、士氣、創傷。
- **關係網**：NPC 之間也有關係，例如陳硯和許安是直屬學長弟、林知夏和蘇沐是室友。一個人死去，會連鎖影響其他人。
- **個人目標**：每個人都有自己想做的事，例如回家找家人、保護某人、搞清楚真相、活下去。目標會和玩家的計畫衝突。
- **遺言**：好感度達到一定程度後，NPC 會在營火夜話中說出一些話。如果他之後死去，這句話會在結算報告中出現。
