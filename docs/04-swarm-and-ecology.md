# 04　蝕群與異變生態

## 1. 蝕群概論

### 1.1 世界中流傳的說法（玩家能聽到的）

- 白教授：「牠們不是外星人。外星人至少會有自己的目的。牠們……更像是一種過程。」
- 林知夏：「每一隻蟲的神經節都太小了，不可能有智慧。除非牠們的大腦不在身體裡。」
- 黃伯：「我年輕的時候，後山也有過這種蟲。一隻，就一隻。你們學長把牠打死了，燒了。之後就再也沒人提。」

### 1.2 生態迴路

```text
        擄人／捕獸／吞食異化植物
               │
               ▼
   ┌──────► 生物量 ──────────┐
   │           │              │
   │           ▼              ▼
   │        繭池（孵化）    裂隙擴張（口徑提升）
   │           │              │
   │           ▼              ▼
   │        新的蟲 ◄────── 更大的兵種可以通過
   │           │
   │           ▼
   │        巢苔擴散（蟲的視野與速度提升）
   │           │
   └──── 群思學習（玩家的戰術 → 抗性演化）
```

**玩家能介入的節點**（這是讓難度可以被玩家影響的關鍵）：

| 節點 | 玩家行動 | 效果 |
|---|---|---|
| 擄人 | 救回被拖走的人（刑事系可以追蹤拖行痕跡） | 生物量減少，倖存者增加 |
| 繭池 | 焚燒、炸毀 | 生物量大幅減少，但會引發報復性蟲潮 |
| 巢苔 | 火燒、驅蟲艾、蒸汽 | 奪回地形 |
| 裂隙 | 小裂隙可以封印（黑鐵印碎片、特定異能、白澤的知識） | 減少出兵點 |
| 群思 | 變換戰術、解碼蟲語、餵假情報 | 拖慢適應，甚至誤導牠們 |

### 1.3 裂隙口徑（難度的世界邏輯核心）

| 口徑 | 名稱 | 寬度 | 典型時段 | 可通過的兵種 | 世界變化 |
|---|---|---|---|---|---|
| I | **針孔** | < 0.5 m | 交融波後 0–6 小時 | 蝕蝨、哨翅、穿岩幼蟲 | 天空出現墨色裂紋 |
| II | **門** | < 2 m | 6–24 小時 | 拾骸者、彈刃、潰液、畫皮、蛹語者 | 巢苔開始蔓延 |
| III | **閘** | < 5 m | 24–48 小時 | 鐵殼、頌者、巢衛、穿岩成體 | 異界天候出現 |
| IV | **穹** | > 5 m | 48–64 小時 | 巢獸、將級蟲 | 疊合率超過 60%，物理規則改變 |
| V | **天裂** | 無上限 | 64 小時以後 | 女王／Boss 本體 | 天空裂開，兩個月亮可見 |

> 時段是**預設值**。實際的擴張速度取決於生物量。玩家表現得好，第四階段可能延後十小時；表現得差，第二天中午天就裂了。

## 3. 群思：會學習的敵人

### 3.1 感知網

- 哨翅與巢苔是群思的「眼睛」。在巢苔上，你的位置對牠們是公開的。
- **擊落哨翅可以保持隱蔽**。讓牠飛回去，就代表下一波會精準地來找你。

### 3.2 戰術行為（依階段解鎖）

| 階段 | 新的戰術 |
|---|---|
| 第一幕 | 單純的獵食與擄人 |
| 第一夜 | **試探**：小規模攻擊據點的每一面，找出最弱的一面 |
| 第三幕 | **包圍**、**佯攻**（正面佯攻、從側面或地下主攻）、**獵捕落單者** |
| 第四幕 | **切斷補給**（攻擊遠征隊）、**針對光源與發電機**、**擬態滲透** |
| 終幕 | **斬首**：優先攻擊玩家中最強的覺醒者 |

### 3.3 適應系統：戰術帳本

群思會維護一本「**戰術帳本**」，記錄玩家的殺敵手段：

```text
帳本分類：火焰 / 電擊 / 彈道 / 近戰 / 爆炸 / 光 / 聲 / 水 / 潛行 / 載具 / 各異能本源
每一波結束後：
  若某分類的佔比 > 35%，且累計擊殺數 > 門檻
    → 下一個繁殖週期，新生的蟲獲得對應的抗性特徵
  抗性上限：同時最多 3 種（避免變成無敵）
  抗性衰退：某分類連續兩個週期沒被使用，抗性會減弱（逼玩家輪替戰術，而不是永遠封印某個手段）
```

| 玩家的習慣 | 群思的回應 | 預告方式 | 反制的反制 |
|---|---|---|---|
| 大量用火 | **濕潤甲殼**，抗火 | 鑑識：「外殼含水量提高 40%」；蟲的外表變得濕亮 | 濕的甲殼導電 → 改用電 |
| 大量用電 | 絕緣甲殼 | 甲殼變得暗沉、粗糙 | 絕緣層很脆 → 改用近戰鈍擊 |
| 大量用槍 | 厚甲 | 體型變大、動作變慢 | 速度變慢 → 改用潛行繞過 |
| 夜間打燈 | **盲蟲**（沒有眼睛） | 外事系解碼：「牠們說……閉上眼睛」 | 盲蟲對振動極度敏感 → 用振動誘餌 |
| 載具衝撞 | 穿岩伏擊道路 | 路面出現隆起 | 改走水路或空路 |
| 潛行 | 哨翅倍增、巢苔擴散加速 | 天空的哨翅變多 | 集中火力打下哨翅 |
| 某個玩家的異能 | 針對該本源的抗性 | 蟲族評價會提到「那個會發光的碎片」 | 共鳴（組合技的抗性要分開學） |

> **公平性原則**：每一項演化都要**先預告、再生效**，而且一定有一個反制方法。結算報告中的「蟲族評價」就是從這本帳本生成的。

### 3.4 群思之聲

- 群思是由所有被吞噬者的聲音組成的合唱。
- 如果你的同學被擄走而沒有被救回，**他的聲音會出現在群思之中**：
  - 頌者附近的無線電干擾中，會夾雜著他的聲音，在叫你的名字。
  - 對話結局中，你可以找到他的聲音並把他「帶出來」（以某種形式）。
  - 結算報告的蟲族評價中，會出現他的聲音片段。

## 5. Boss（每局一位主 Boss）

> 抽選邏輯：種子決定兩位候選，**群思根據玩家這局的表現選擇其中一位**。例如玩家發掘了大量異能，鏡后的機率就會提高；玩家多次擊退寄生，蛹王的機率就會提高。Boss 本身也是群思適應的一部分。

### 5.1 千眼之母（經典王）
- **場地**：主裂隙正下方的巨型繭池。
- **世界觀**：裂隙的「錨」，裂隙因為她而存在。
- **機制**：三階段。第一階段打掉守護眼；第二階段她會把整個繭池的人蛹當作盾牌（要先救人才能打）；第三階段她會試圖鑽回裂隙。
- **知識鎖解法**：如果你在之前的事件中得知「她怕熄燈號」，在廣播室播放熄燈號，她會停頓 30 秒。

### 5.2 鏡后
- **場地**：圖書館的地下書庫，一座由鏡子構成的迷宮。
- **世界觀**：群思最接近「個體」的存在，專門研究人類。
- **機制**：她會**複製這一局中玩家已經發現的所有異能**。你發現得越多，她就越強。
- **知識鎖解法**：她同時繼承了你的鑰匙與代價。如果你知道自己異能的代價（例如「使用後三秒無聲」），就能利用她使用該異能後的破綻。**了解自己，就是打敗她的方法。**

### 5.3 蛹王
- **場地**：至善堂。
- **世界觀**：一位被寄生的關鍵人物（最常見的是區隊長嚴振東，也可能是陳硯、孟昭）。
- **機制**：他保留了生前的戰鬥技巧與記憶，會用警察的戰術對付你（盾陣、破門、指揮蟲群）。
- **知識鎖解法**：如果事先在鑑識大樓研究出寄生解方，並在戰鬥中把解方注射給他，就能**救回他**。他會說出一段話（區隊長：「……你們這群兔崽子。做得好。」）。
- **情感核心**：你們熟悉的那個人。

### 5.4 百足鐘
- **場地**：鐘樓與水塔，垂直的戰場。
- **世界觀**：一隻巨型蜈蚣纏繞在鐘樓上，與七大不可思議中「整點自己響的鐘」有關。
- **機制**：每到整點，鐘聲會讓所有異能失效十秒；而牠的弱點只有在鐘響時才會露出來。
- **知識鎖解法**：用異能以外的手段，在鐘響的十秒內攻擊弱點。

### 5.5 沉默者
- **場地**：射擊館與械彈庫。
- **世界觀**：一隻會吃掉聲音的透明大蟲。
- **機制**：牠周圍沒有聲音。你聽不到牠，所有聲系異能失效，無線電失效。**在聲紋偵測模式下，牠聽得見你的麥克風。**
- **知識鎖解法**：撒粉、潑水、在雨中讓牠現形；用手勢（肢體輪盤）溝通。

### 5.6 巢獸「山」
- **場地**：田徑場到台地邊緣，開闊地帶。
- **世界觀**：裂隙口徑達到「穹」之後才能通過的巨大生物，一座會走路的山。
- **機制**：巨像攀爬戰。玩家要爬到牠的身上，破壞三個巢心。地面上的隊友負責吸引牠的注意力，以及清除牠持續生出的小蟲。
- **知識鎖解法**：蒼淵異獸「負嶽」（如果你們救過牠）會出現，和巢獸角力。

## 6. 蒼淵異獸

> 異獸是**難民**，不是侵略者。牠們和蝕群是幾億年的宿敵。

| 異獸 | 外觀 | 態度 | 互動 | 獎勵 |
|---|---|---|---|---|
| **白澤** | 白色的大鹿與獅之間，額上有第三隻眼 | 中立、全知、疲倦 | 三道試煉：回答牠的問題（關於你自己的選擇） | 一把異能鑰匙，或者 Boss 的弱點，或者真相層的一片碎片 |
| 夔（幼獸） | 單足、雷光 | 受傷、驚恐 | 治療牠 | 雷系異能者的真名；雷雨夜的盟友 |
| 畢方 | 單足火鳥 | 暴躁 | 讓牠在消防訓練場築巢 | 永不熄滅的火種 |
| 負嶽 | 背上長著石頭的巨龜 | 溫和、遲緩 | 引導牠避開蟲群 | 終局對抗巢獸的盟友 |
| 霧鹿群「靄」 | 半透明的鹿群 | 逃亡中 | **異獸過境事件**：庇護牠們，或者把牠們當誘餌 | 庇護 → 霧鹿會在之後的濃霧中為你引路 |
| 影狐 | 只有影子的狐 | 好奇 | 和牠玩捉迷藏 | 影系異能的提示 |
| 雨師（幼鳥） | 青色的水鳥 | 依賴 | 雨天才會出現 | 水系異能的真名 |
| 被寄生的異獸 | 任何異獸 | 敵對 | 擊敗後有機會淨化 | 淨化後成為盟友 |

**獸印**：異獸能認出與自己同源的覺醒者。當你的異能真名正好是牠的同族時，牠會對你低頭，觸發專屬事件。
