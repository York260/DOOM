## 2. 彩蛋（28 個）

### 數字 7
1. 第三中隊第七區隊、交融波的預設時刻 07:42、七大不可思議、忠勇牆上的七個空格。
2. 自動販賣機要投七枚硬幣。
3. 擲幣的極鑰是連續七次正面。

### 熄燈號
4. 每天 22:30，廣播系統會嘗試播放熄燈號。如果排程已經修復，在熄燈號播放時**敬禮**，忠勇牆會發出微光，一支前輩組成的儀隊殘影會出現十秒，蟲群會停下來。
5. 在熄燈號播放時唱校歌（哨令的極鑰）會觸發特殊過場。
6. 1972 年畢業紀念冊的最後一頁，是熄燈號的手寫樂譜，音符旁邊寫著：「不要停。」

### 校園生活
7. 賴床三次，交融波發生時你還在床上，開場變成「從宿舍的窗戶看著天空裂開」。
8. 內務滿分可以獲得「紀律」增益。區隊長會說：「末日也要摺棉被。」
9. 序章時如果爬上鐘樓用望遠鏡看天空，你會提早十分鐘看見裂隙的形成，並且得到「先知」線索。
10. 期末考週的考卷：誠實作答，它會寫出你的異能本源。作弊，它會寫：「你知道你自己是誰嗎？」

### 角色
11. 豆漿的異能在每條時間線中幾乎都和食物有關。真名揭曉的時候，你會發現他的天賦來自蒼淵一隻叫「饕餮之子」的小獸。
12. 歐陽品睿的綽號是「Bug」。群思偶爾會把他誤認為同類，導致他可以在蟲群中短暫潛行。
13. 小蟬哼的那首歌，在隱藏頻道中可以聽到完整版。用八方心共感一隻蟲時，你會聽到同一首歌。
14. 阿月姨的異能是運氣，但她自己完全不知道。結算時如果她還活著，她的評價會是：「我這輩子運氣都很好啊，怎麼了？」
15. 小八的狗屋裡藏著區隊長寫給女兒但從未寄出的信。

### 致敬
16. 消防訓練場的鎖櫃中有一把鏈鋸，便條紙上寫著「Rip and tear.」（致敬本專案代號）。
17. 資訊系電腦教室裡有一台老電腦，螢幕上跑著一款 90 年代的第一人稱射擊遊戲。在終端機輸入 `IDDQD`，畫面會顯示：「這裡沒有神。」並解鎖一次十秒的無敵，代價是之後隨機觸發一次幸運反噬。
18. 小八的名字是對忠犬八公的致敬。

### 台灣味
19. 早餐店的大冰奶：大量回復體力。描述寫著：「嚴格來說它沒有異化。它本來就這麼強。」
20. 鹹酥雞攤的香味會同時吸引蟲和倖存者。老闆說：「末日也要吃宵夜。」
21. 土地公廟附近的蟲總是繞道。遊戲永遠不解釋原因。供上大冰奶的話，廟裡的燈會亮一下。
22. 統一發票：擲幣異能的徵兆之一是「上次發票對中了兩百塊」。
23. 颱風夜開局，一位 NPC 會抱怨：「颱風假放了，結果世界末日。」

### 時間線
24. 深夜靶場會重播你在過去局中的死亡瞬間。
25. 「那本不存在的書」裡，會寫著你上一局結算報告的節錄。
26. 十三號置物櫃可以和好友交換物品。
27. 在鏡像校園模組中，校長銅像會轉頭轉到另一邊。
28. 集齊零號時間線碎片之後，標題畫面的升旗台上會多出七個人影。

## 3. 跨局成長

> 原則：**跨局累積的是知識、選擇與回憶，不是數值。**

### 3.1 檔案館（主選單）

| 區塊 | 內容 |
|---|---|
| 異能語法錄 | 你遇過的本源、顯化、鑰類、代價，以及它們對應的徵兆。這是「語法」的累積，讓你下一局可以推理得更快 |
| 蟲族圖鑑 | 解剖過的兵種、弱點、演化紀錄 |
| 異獸錄 | 遇見過的蒼淵異獸 |
| 人物誌 | 每位 NPC 在你所有時間線中的命運，例如「陳硯：英雄 4 次、殉職 3 次、逃走 1 次、被寄生 1 次」 |
| 傳說錄 | 七大不可思議 |
| 結局錄 | 達成過的結局 |
| 報告庫 | 所有局的結算報告 |

### 3.2 時間線樹

- 把你所有的局畫成一棵**分歧的樹**。每一局是一條枝，節點是關鍵抉擇。
- 你可以點開任何一條枝，看見那條時間線的報告。
- 同種子的局會長在同一根主幹上，讓你直接看見「同一條時間線，因為不同的選擇而分歧」。

### 3.3 解鎖項目

| 類別 | 項目 | 解鎖方式 |
|---|---|---|
| 系別 | 外事系、國境警察系、犯罪防治系、行政警察系 | 成就 |
| 開局日 | 颱風夜、畢業典禮前夜…… | 通關次數 |
| 說書人 | 說書人、判官 | 通關次數 |
| 世界線變異 | 永夜、鏡像校園…… | 特定成就 |
| 外觀 | 制服臂章、警徽樣式、勤務手冊封面 | 成就、評級 |
| 遺物 | 上一局的某件物品，會在下一局的世界中某處被找到 | 結算時選擇 |

### 3.4 零號時間線（跨局大謎團）

- **15 片碎片**，分散在不同的局、不同的傳說、不同的結局中，例如：
  1. 1972 年的畢業紀念冊（圖書館）
  2. 白教授的剪報牆（第三幕事件）
  3. 後山的老兵的話（七大不可思議之七）
  4. 低溫櫃裡的組織樣本（鑑識大樓）
  5. 熄燈號的手寫樂譜（畢業紀念冊最後一頁）
  6. 一台舊巡邏車的行車紀錄器（駕訓場）
  7. 守四舍多出來的那一層裡的日記
  8. 白澤的第三道試煉的答案
  9. 物憶的極鑰：觸碰自己的倒影
  10. 對話結局中，群思最深處的一個聲音
  11. 封裂結局的代價
  12. 錨點結局中，母巢核心裡的東西
  13. 小蟬那首歌的完整版
  14. 判官說書人下的全滅結局後續
  15. 在七條不同開局日的時間線中，各自聽完一次熄燈號
- **集齊後**：解鎖「零號」祕密結局。玩家會知道 1972 年封住裂隙的那群警校生是誰，知道熄燈號為什麼不能停，也知道忠勇牆上那七個空格在等誰。
- **最後一個鏡頭**：七個名字被刻上忠勇牆。其中幾個，是你的隊友的名字。

## 4. 長期營運（發售後）

| 類型 | 內容 |
|---|---|
| 季節時間線 | 限時開局日，例如「中秋烤肉夜」（烤肉的煙會吸引蟲，也能驅蟲）、「跨年夜」（煙火是最好的誘餌，也是最好的武器） |
| 社群種子 | 每週公布一條「本週時間線」，全球玩家玩同一個種子，比較結局分布 |
| 新本源與新兵種 | 擴充異能語法與蟲族生態 |
| 新舞台（大型更新） | 雲台市的其他地方：港口、捷運地下、醫學中心 |
| 原則 | 不販售數值，不販售異能。付費內容只有外觀與大型擴充 |
