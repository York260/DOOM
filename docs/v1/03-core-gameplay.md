# 03　核心玩法

## 1. 多尺度核心循環

```text
┌─ 30 秒 ─────────────────────────────────────────────┐
│ 觀察 → 移動／潛行 → 戰鬥 or 迴避 → 試驗異能 → 搜刮     │
└──────────────────────────────────────────────────────┘
┌─ 5 分鐘 ─────────────────────────────────────────────┐
│ 事件（救援／搜索／遭遇／抉擇）→ 結果寫入事蹟記錄器      │
└──────────────────────────────────────────────────────┘
┌─ 30 分鐘（一個幕段）────────────────────────────────┐
│ 喘息期（據點、營火夜話、研究）→ 遠征 → 防守 → 喘息期   │
└──────────────────────────────────────────────────────┘
┌─ 一局（約 2.5–3 小時，遊戲內 72 小時）──────────────┐
│ 序章 → 五幕 → Boss → 結局 → 結算報告 → 留下殘響       │
└──────────────────────────────────────────────────────┘
┌─ 跨局 ──────────────────────────────────────────────┐
│ 異能語法、圖鑑、地圖祕密、傳說、殘響、零號時間線碎片    │
└──────────────────────────────────────────────────────┘
```

**每個循環都有一個「未知」**：30 秒的未知是「轉角有什麼」，5 分鐘的未知是「這個人值不值得信任」，30 分鐘的未知是「今晚牠們會從哪裡來」，一局的未知是「我到底是誰」，跨局的未知是「這一切為什麼會發生」。

## 2. 視角、移動與操作

- **視角**：第三人稱肩後視角，舉槍瞄準時可以切換為第一人稱（可在設定中改為全程第一人稱）。
- **移動**：奔跑、蹲伏、匍匐、攀爬、翻越、游泳、背負傷患、拖行傷患。
- **掩體系統**：輕量，可以貼牆，但不會自動吸附。
- **肢體輪盤**（關鍵設計）：12 個動作，敬禮、拍手、吹口哨、屏息（按住）、閉眼、蹲伏靜止、雙手合十、舉手投降、比讚、擲硬幣、亮警徽、背靠背邀請。
  - 這些動作平常可以拿來溝通（多人模式下不開麥克風也能交流），**同時也是異能鑰匙的實驗工具**。
  - 新手教學只告訴你「這些動作是用來溝通的」，不會告訴你它們跟異能的關係。

## 3. 戰鬥：警察的方式

### 3.1 武器與裝備

| 裝備 | 取得 | 對蟲的效果 | 備註 |
|---|---|---|---|
| 伸縮警棍 | 初始 | 弱，但可以擊退蝕蝨 | 可以附加熔掌、逆雷 |
| 防暴盾牌 | 體育館器材室、分局 | 擋酸液、擋彈刃 | 盾陣的核心 |
| 辣椒噴霧 | 初始 | 只對「氣味型」蟲有效（哨翅、拾骸者） | 鑑識過後才知道對誰有效 |
| 電擊槍 | 分局 | 對軟殼蟲有效，對鐵殼無效 | 也可以用來「重啟」被寄生的人？（事件） |
| 制式手槍 9mm | **械彈庫** | 中等，打弱點才有效 | 彈藥有限，槍聲會吸引蟲 |
| 霰彈槍 | 分局、械彈庫深處 | 近距離強 | 稀有 |
| 訓練用步槍 | 射擊館 | 遠距離 | 子彈極度稀缺 |
| 消防斧 | 消防訓練場 | 強，可破甲 | 也是破門工具 |
| 消防水帶 | 消防車、消防栓 | 擊退＋沖掉信息素標記 | 和雷、寒系共鳴 |
| 滅火器 | 到處都有 | 冰凍、致盲 | 很多人會忘記它的戰鬥用途 |
| 汽油彈 | 自製（加油站） | 範圍火焰 | 群思會學會抗火 |
| 煙霧彈 | 消防訓練場 | 遮蔽視線，對蝕蝨有迷向效果 | — |
| 鎮暴網槍 | 分局 | 束縛中型蟲 | 救援時很好用 |
| 手銬 | 初始 | 對人：逮捕 | 被寄生者可以先銬住，等待治療 |
| 警用無線電 | 初始 | — | 通訊工具，見 `06` |
| 手電筒 | 初始 | 對趨光蟲：吸引；對畏光蟲：驅趕 | 雙面刃 |
| 警笛（載具） | 警車 | 大範圍引誘 | 最強的誘敵工具 |
| **鏈鋸** | 消防訓練場的鎖櫃（彩蛋） | 極強 | 櫃子上貼著便條：「Rip and tear.」 |

### 3.2 械彈庫：槍是要「爭取」來的

- 警校的槍不會散落在地上，它們鎖在械彈庫裡。
- 械彈庫是**雙鑰制**：一把在區隊長嚴振東身上，一把在值星學長陳硯身上。交融波發生時，兩人可能昏迷、失蹤、在不同的地方，或者其中一人已經死了。
- **取得方式**（開放式）：
  1. 找到兩位持鑰人，說服他們（區隊長堅持「學生不能持槍」，需要犯防系或劇情事件說服）。
  2. 資訊系駭入電子鎖（會觸發警報，吸引蟲）。
  3. 消防系破拆（費時，噪音很大）。
  4. 傳說中的「第三把鑰匙」（老黃知道，七大不可思議線索）。
  5. 異能（例如對調系把鑰匙「寄」過來、金系直接開鎖）。
- **彈藥是有限的資源**，一局的總彈藥量是固定的（由種子決定），用完就沒了。這逼玩家思考什麼時候該開槍。

### 3.3 弱點系統：鑑識即知識

- 每種蟲都有 2–3 個弱點（甲殼縫隙、關節、氣門、酸囊、感覺器官）。
- **在解剖之前，弱點不會在畫面上顯示。**玩家可以靠觀察和運氣打中，但無法穩定命中。
- 把蟲屍（或部位）帶回鑑識大樓解剖後，弱點就會永久顯示（本局）；並寫入跨局圖鑑（下一局只要有一位隊員帶著圖鑑知識，弱點就會顯示，但群思的演化會讓弱點的位置偏移）。
- 解剖小遊戲：用工具切開、取樣、分析，由林知夏或鑑識系玩家主持。

### 3.4 小隊指令與隊形

| 指令 | 效果 |
|---|---|
| 跟隨／停留 | 基本 |
| 掩護 | NPC 對指定方向射擊或防守 |
| **盾陣** | 持盾者在前排排成一列，後排射擊；可以緩慢推進 |
| **圓陣（背靠背）** | 四面防守，適合被包圍時 |
| 縱列推進 | 走廊與室內 |
| 破門 | 見 §3.5 |
| 搜索 | NPC 自行搜刮房間 |
| 守點 | NPC 守住指定位置 |
| 後送 | NPC 把傷患送回據點 |
| 撤退 | 全員撤到指定集合點 |

### 3.5 破門與清房（CQB）

- **堆疊**：在門邊排隊，指定第一名進入的人。
- **破門方式**：踹門、破門槌、消防斧、霰彈槍、異能。
- **投擲物**：閃光彈（對趨光蟲反而有吸引效果）、煙霧彈。
- **清房**：分配角落。房間清除後，NPC 會回報：「左邊淨空！」「右邊淨空！」
- 多人模式中，四個人一起完成一次乾淨的破門清房，會觸發「教科書」成就。

### 3.6 警察倫理：非致命選項

| 對象 | 選項 | 後果 |
|---|---|---|
| 恐慌暴民 | 喝令、制伏、上銬、拘留到據點的拘留室 | 「品格」評分；若濫用武力，派系仇恨會上升 |
| 劫掠者 | 談判、逮捕、交火 | 逮捕的劫掠者可能成為勞動力，也可能在夜裡逃跑放蟲進來 |
| 被寄生者 | 上銬隔離 → 30 分鐘內手術移除寄生卵 → 救回；或者處決 | 救回會大幅提升「品格」與倖存者評價；處決會讓警徽異能失效 |
| 失控覺醒者 | 安撫（犯防系）、壓制、等它結束 | 失控的人常常是許安 |

### 3.7 蟲族的三種感官（潛行系統）

| 感官 | 觸發 | 對策 |
|---|---|---|
| **振動／聲音** | 奔跑、槍聲、說話（聲紋偵測）、載具 | 蹲走、消音、靜音 |
| **光／熱** | 手電筒、火焰、體溫 | 關燈、冷卻、異能遮蔽 |
| **氣味／信息素** | 血、汗、被哨翅標記 | 洗澡（真的）、消防水帶沖洗、驅蟲艾 |

- 不同兵種偏重不同的感官，例如蝕蝨主要依靠振動，哨翅依靠光與信息素，盲蟲只靠振動。
- **信息素標記**：被哨翅擦過之後，你身上會帶著標記，會被持續追獵，直到洗掉為止。你可以利用這一點，故意被標記，然後把蟲群引到陷阱裡。

## 4. 生存：壓力而非家務

> 原則：生存數值的目的是製造**決策**，而不是讓玩家每十分鐘按一次吃飯鍵。

| 數值 | 速度 | 影響 | 設計意圖 |
|---|---|---|---|
| 生命／傷勢 | 依戰鬥 | 部位傷：頭（視野）、軀幹（出血）、四肢（移動與瞄準） | 受傷要處理，不能只吃血包 |
| 出血 | 快 | 持續失血，吸引蟲 | 止血帶是珍貴物品 |
| 骨折 | — | 移動或瞄準大幅下降 | 夾板，或請隊友揹著走 |
| 酸蝕 | 中 | 裝備損壞 | 需要沖水 |
| **寄生卵** | 30 分鐘倒數 | 時間到 → 被寄生，變成敵人（玩家則進入「寄生狀態」） | 最緊張的倒數；需要手術移除 |
| 體力 | 快 | 奔跑、近戰、游泳 | 戰術節奏 |
| **壓力** | 依事件 | 高壓力時：瞄準晃動、出現幻聽；**某些異能的鑰匙需要高壓力** | 恐懼是阻礙，也是機會 |
| 創傷 | 累積 | 永久性的怪癖（本局）：例如「怕黑」「不敢單獨行動」 | 戲劇性 |
| 飢餓／口渴 | 慢 | 第二天之後才開始有壓力 | 物資規劃 |
| 疲勞 | 中 | 需要睡眠；睡眠時會做夢（異能線索） | 站哨輪班 |
| 體溫 | 依天氣 | 寒系代價、孢子霧寒夜 | — |

## 5. 據點

### 5.1 候選據點

| 據點 | 優點 | 缺點 | 特色 |
|---|---|---|---|
| 學生宿舍 | 床鋪、個人物品、熟悉 | 走廊型、易燃、出入口多 | 「家」的感覺，士氣加成 |
| 綜合體育館 | 空間大，可收容大量倖存者 | 鋼構屋頂薄，哨翅會從天窗進來 | 收容數最多 |
| **射擊館** | 厚牆、隔音（噪音不外洩）、靠近械彈庫 | 只有一個出入口（被堵就完了） | 最堅固，但也最像棺材 |
| 圖書館 | 研究速度加成，高窗可以狙擊 | 易燃，地下書庫有穿岩 | 知識型據點 |
| 行政大樓 | 廣播室、監視器、發電機 | 樓層多，難以全面防守 | 情報型據點 |
| 消防訓練場 | 消防車、空氣呼吸器、水源 | 偏僻 | 機動型據點 |
| 長青醫院（遠征） | 醫療物資豐富 | 繭池高機率在附近 | 高風險高報酬 |

- 可以同時擁有多個據點（主據點＋前哨），但守備力會分散。
- 據點可以**轉移**。在戰況惡化時舉行「大撤退」，這本身就是一個高潮事件。

### 5.2 建設類別

| 類別 | 項目 |
|---|---|
| 防禦 | 拒馬、沙包、鐵捲門加固、鐵絲網、盾牆、封窗 |
| 感官 | 照明（雙面刃）、隔音、監視器、警報鈴（空罐頭繩） |
| 陷阱 | 消防水帶＋雷系＝電網、油桶火牆、警笛誘餌、坑洞 |
| 驅蟲 | 驅蟲艾種植區、煙燻爐 |
| 生活 | 床鋪、廚房、淨水器、廁所（真的有：衛生影響疾病） |
| 醫療 | 醫療站、手術台（寄生卵移除） |
| 研究 | 鑑識工作台、異能測試艙（需要鑑識大樓）、蟲語解碼台 |
| 通訊 | 無線電中繼、天線、廣播系統 |
| 拘留室 | 關押暴民、被寄生者 |
| 紀念 | **點名牆**：倖存者把殉職同學的名字寫在牆上（士氣與悲傷同時產生） |

### 5.3 夜間防衛流程

1. **黃昏部署**：分配哨位、確認陷阱、清點彈藥、晚點名。
2. **站哨**：玩家與 NPC 輪班。NPC 哨兵在疲勞、恐懼時會打瞌睡或謊報。玩家可以「查哨」。
3. **襲擊**：群思會尋找最弱的一面進攻（不是隨機的）。
4. **天亮修復**：清點損失，點名表更新。

### 5.4 勤務規章（據點的「法律」）

- 玩家可以制定據點規章，例如配給制、宵禁、異能登記、每日寄生檢查、禁止單獨外出、覺醒者優先撤離……
- 每條規章都會影響派系平衡、士氣與效率，也會寫入結算報告的「品格」評價。
- 這是一種輕量版的《冰汽時代》法典，但帶有警察的味道：玩家既是執法者，也是立法者。

## 6. 倖存者

### 6.1 招募與指揮

- **招募**：救援、說服（犯防系加成）、命令（年級與行政系加成）、交易。
- **職務**：哨兵、醫護、廚師、研究員、工程、斥候、照顧者、通訊員。
- **派遣任務**：把 NPC 派出去執行遠征任務。他們不在畫面上，結果會透過**無線電劇場**即時回報，例如：「七號呼叫據點……我們找到藥了……等一下，那是什麼聲音……」（玩家可以決定要不要去救）。

### 6.2 NPC 自主

- 每個 NPC 都有自己的目標。如果長期不滿，他們會離開、偷東西，或者自己行動。
- 在戲劇高潮時，NPC 會主動做出犧牲或英雄行為（由敘事導演評估時機，見 `05`）。

### 6.3 派系

| 派系 | 主張 | 常見領袖 | 衝突事件 |
|---|---|---|---|
| 教官派 | 秩序、指揮鏈、等待救援 | 嚴振東、孟昭 | 「學生不能持槍」 |
| 自治派 | 民主決策、輪流領導 | 陳硯 | 投票事件 |
| 覺醒者至上 | 異能者應該優先分配物資與撤離 | 隨機 | 政變事件 |
| 常人互助會 | 常人是被犧牲的一群，需要保護 | 隨機 | 分裂出走 |
| 鎮民 | 回家、找家人、拜拜 | 土地公廟的廟公 | 要求護送回鎮上 |

## 7. 探索

### 7.1 開放世界的邏輯門

- 沒有隱形牆，門鎖靠**世界邏輯**：上鎖的門、門禁卡、雙鑰、巢苔覆蓋區、坍塌、深水、毒霧。
- 每一道門都有多種解法（系別、異能、物品、NPC）。

### 7.2 載具

| 載具 | 特色 |
|---|---|
| 警車 | **警笛＝大範圍誘餌**；後座可以載被銬住的人 |
| 警用機車 | 快速、靈活，噪音很大 |
| 校車 | 一次撤離大量倖存者 |
| 消防車 | 水砲、雲梯（可以攻上鐘樓） |
| 救護車 | 移動醫療站 |
| 小艇（水上警察系） | 鏡湖與排水道路線 |
| 無人機（資訊系） | 偵察、投放誘餌 |

### 7.3 手機

- **相機**：拍下蟲的照片可以累積部分鑑識資料（不如解剖完整）。
- **錄音**：錄下蟲語，交給外事系解碼。
- **群組訊息**：交融波之前的訊息透露了劇情線索（例如有人在前一晚的班群裡說「後山好像有光」）；交融波之後，訊號偶爾恢復，會收到零星的訊息，有時是求救，有時是陷阱。
- **電量**：會用完，需要充電。

### 7.4 無線電頻道

| 頻道 | 內容 |
|---|---|
| CH1 | 小隊頻道（玩家之間） |
| CH2 | 據點頻道 |
| CH7 | 雲台分局（趙守仁局長） |
| CH9 | 軍方（第三幕以後出現） |
| 隱藏頻道 | 數字電台（一個女聲在念數字，那是座標）／另一條時間線的聲音／一首熄燈號的片段 |
| 蟲語干擾 | 頌者在附近時，所有頻道會混入蟲語 |

## 8. 介面與體驗

### 8.1 最小化介面＋敘事型介面

- **常駐**：準星、手錶（時間、心率＝壓力的直覺呈現）、彈藥、點名表（可收合）。
- **點名表**：第七區隊 12 位同學，加上收容的倖存者。狀態有「在」「傷」「失聯」「殉職」「寄生」。每晚 22:00 晚點名時會自動展開，一個一個名字被念出。少了人的時候，那一欄會停頓一秒。
- **勤務手冊**：異能、線索、地圖、任務、倖存者資料。
- **無線電**：語音與文字紀錄。

### 8.2 小說化演出

- **章回標題卡**：進入新的一幕或發生重大事件時出現，章名依事件生成（見 `05`）。
- **定格句**：關鍵瞬間，畫面放慢到 20% 速度，浮現一行小說句子，約 2 秒，不打斷操作。
- **旁白**：可選擇開啟的旁白配音（三位說書人有不同的聲線）。

| 選項 | 內容 |
|---|---|
