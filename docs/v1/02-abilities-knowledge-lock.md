# 02　異能系統：知識鎖

## 1. 設計目標

| 目標 | 說明 |
|---|---|
| **Eureka 時刻** | 「原來是這樣！」的發現瞬間，是整個遊戲最重要的情緒峰值。我們要設計它、保護它，也要放大它（定格句、章回標題） |
| **知識就是解鎖** | 沒有經驗值，也沒有技能樹點數。你知道鑰匙，第一分鐘就能用；你不知道，七十二小時都用不出來 |
| **每局不同，但可以學** | 鎖的是「語法」而不是「答案」（見 `00` 建議 1）。老手推理得比較快，但永遠有沒見過的組合 |
| **強大有重量** | 每一次使用都要付出代價，而且代價會直接改變你的感官 |
| **合作的拼圖** | 隊友的異能你也看不到，必須互相描述、互相觀察、一起實驗，才能發現「共鳴」 |
| **不會卡死** | 提示階梯保證每個人在合理時間內都能至少發現第一層 |

## 2. 異能的六個元件

```
異能 = 本源 × 顯化 × 鑰（主鑰 + 枝鑰 + 極鑰）× 代價 + 徵兆 + 真名
```

### 2.1 本源（這是什麼力量）：20 種

| 稀有度 | 本源 | 典型徵兆 | 常見代價傾向 |
|---|---|---|---|
| 普通 | 熱 | 手心總是很燙；冰塊在你手裡融化得特別快 | 飽食、口渴 |
| 普通 | 寒 | 室內呼氣起霧；杯裡的水結霜 | 體溫 |
| 普通 | 雷 | 門把一直電你；手錶停了；你一靠近，無線電雜訊就變大 | 周遭的電子設備故障 |
| 普通 | 聲 | 聽得到牆後的對話；耳鳴的頻率會變 | 聽覺 |
| 普通 | 光 | 在黑暗中視力很好；你的影子比別人淡 | 色彩 |
| 普通 | 影 | 你的影子偶爾比你慢半拍 | 光敏 |
| 普通 | 重 | 東西在你手邊掉得比較慢；你跳得比別人高 | 體力 |
| 普通 | 水 | 下雨時覺得特別清醒；水面映出的你在眨眼 | 聽覺、體溫 |
| 普通 | 風 | 你身邊的紙張總是在飄 | 呼吸（體力） |
| 普通 | 木 | 你經過的草長得比較快；花朝你的方向轉 | 飢餓 |
| 罕見 | 血 | 傷口癒合得異常快；你能聞到別人的血 | 理智 |
| 罕見 | 金 | 金屬在你手裡會「嗡」一聲 | 痛覺 |
| 罕見 | 速 | 有時候覺得別人說話很慢 | 壽命（頭髮變白） |
| 罕見 | 心 | 聽得見他人的心跳；動物特別親近你 | 理智、他人代價 |
| 罕見 | 界 | 偶爾一眨眼就站在半步之外；鏡子裡的你會延遲 | 記憶 |
| 罕見 | 生 | 你碰過的傷口不太流血；枯萎的盆栽活了 | 壽命 |
| 傳說 | 數（機率） | 擲硬幣總是正面；剛好每次都抽到對的籤 | 幸運反噬（之後發生壞的隨機事件） |
| 傳說 | 憶 | 摸到物品時，腦中閃過不屬於你的畫面 | 記憶 |
| 傳說 | 契（規則） | 你說出口的話，別人總是不自覺地照做 | 誓約（違反就會失效） |
| 傳說 | 無 | 沒有任何徵兆。完全沒有 | 無（見「空白者」） |

### 2.2 顯化（力量以什麼形式出現）：8 種

| 顯化 | 說明 | 範例 |
|---|---|---|
| 放 | 放出、投射 | 雷弧、聲波、熱線 |
| 化 | 強化或轉化自身 | 皮膚硬化、身體雷化、影化 |
| 御 | 操縱既有的物質 | 讓雨滴懸停、控制金屬、讓植物生長 |
| 感 | 感知 | 看見物品的記憶、共享動物的感官、預見機率 |
| 域 | 展開一個範圍場 | 低重力場、靜默場、定身場 |
| 附 | 附加到物品上 | 讓警棍發熱、讓子彈帶電 |
| 換 | 交換、轉移 | 與他人交換位置、轉移傷勢 |
| 召 | 具現、召喚 | 長出荊棘牆、製造光之分身 |

本源和顯化之間有**相容表**（例如「心×放」不存在，「憶×感」很常見），讓組合有邏輯，也讓老手可以推理。

### 2.3 鑰（怎麼啟動）：七大類約 40 種

> 鑰匙是知識鎖的核心。每個異能有**一把主鑰**（解鎖第一層）、**一到兩把枝鑰**（解鎖分支）和**一把極鑰**（解鎖極限）。

| 類別 | 鑰匙範例 | 設計說明 |
|---|---|---|
| 姿態鑰 | 屏息（按住）、握拳數到十、拍手、吹口哨、**敬禮**、閉眼、蹲伏靜止三秒、雙手合十、舉手投降 | 全部都在「肢體輪盤」上，讓玩家可以實驗 |
| 情緒鑰 | 恐懼值高於 70、極度冷靜（心跳低於 70）、憤怒（剛看到同伴受傷） | 與壓力系統連動 |
| 環境鑰 | 下雨、黑暗中、高處、水中、火旁、月光下、站在巢苔上、整點鐘響時 | 與天氣、時間連動 |
| 身體鑰 | 流血中、飢餓、奔跑後心跳過快、體溫過低、骨折 | 受傷反而成為機會 |
| 媒介鑰 | 握著金屬、握著警徽、寫下字、說出某個詞（選配麥克風輸入）、觸碰動物、觸碰蟲屍 | 與物品系統連動 |
| 關係鑰 | 與隊友背靠背、牽手、有人陷入危險時、看著某個人的眼睛 | 與多人及 NPC 連動 |
| 時間鑰 | 黃昏、熄燈號播放中、某件事的倒數最後十秒 | 稀有 |
| **逆鑰**（稀有變體） | 「停止」做某件事時觸發：停止奔跑、放開武器、停止說話 | 打破老手的語法直覺 |

**主鑰的可達性保證**：主鑰必須在序章或第一幕的環境中可以達成。生成器會驗證，例如本局的天氣種子前三小時沒有雨，就不會抽到「下雨」當主鑰；或者由敘事導演保證安排一場雨。

### 2.4 代價（強大的重量）：12 種

| 代價 | 數值面 | **感知面（直接改寫介面）** |
|---|---|---|
| 體溫 | 體溫下降 | 畫面邊緣結霜，手部動作變慢 |
| 飽食／口渴 | 快速消耗 | 胃鳴聲（會被蟲聽見） |
| 理智 | 壓力上升 | 出現幻聽，看見不存在的蟲 |
| 痛覺 | 持續受到小傷害 | 畫面震動 |
| **記憶** | — | 地圖標記一個一個消失、物品名稱變成亂碼、NPC 名牌模糊，嚴重時會忘記某位同學的名字（點名表上那一欄變成空白） |
| **色彩** | — | 畫面逐漸去色，最後連蟲的琥珀色螢光都看不見 |
| **聽覺** | — | 使用後數秒完全無聲 |
| 壽命 | 最大生命值緩慢下降 | 角色頭髮逐漸變白（永久外觀，直到本局結束） |
| 噪音 | 每次使用都會發出聲響 | 吸引哨翅 |
| **電子** | 你周圍的電子設備故障 | 隊友的無線電也會沙沙作響，手電筒閃爍 |
| 他人代價 | 吸取附近隊友的體力 | 隊友畫面會出現你的「影子」 |
| 幸運反噬 | 之後觸發一次壞的隨機事件 | 結算時揭露「那次塌方是因為你」 |

### 2.5 徵兆（線索）

- 每個異能有 **3–5 條徵兆**，在序章與第一幕中以「異樣」的形式出現。
- 至少一條徵兆指向**本源**，至少一條指向**主鑰的類別**，另有一條是「假線索」的機率為 20%（提高推理難度，但會在手札中被其他觀察推翻）。
- 徵兆以三種方式呈現：
  1. **環境反應**：門把冒出火花、杯中水結霜。
  2. **NPC 評論**：「你剛剛是不是……你的手在發光？」
  3. **勤務手冊自動記錄**：用第一人稱短句寫成（見 §5）。

### 2.6 真名（這份天賦從哪裡來）

- 每個異能都對應一隻已死的蒼淵亡獸，例如「雨師」「夔」「白狐」「千足」。
- 真名可以透過白澤、同源異獸的反應、校史館的古籍、時間線殘響得知。
- 得知真名後，代價減輕 30%，並獲得一個被動效果。結算報告的「異能揭曉」會以真名作為標題。

## 3. 生成演算法（預算制平衡）

```text
輸入：時間線種子、玩家欄位、系別、背景特質、隊伍中已生成的異能

1. 稀有度擲骰：普通 70% / 罕見 25% / 傳說 5%（「空白者」固定 3%，獨立判定）
2. 抽本源：依稀有度抽取；系別與特質提供輕微加權（例如消防系的「熱」權重 ×1.3）
3. 抽顯化：只從相容表中抽取
4. 抽主鑰：依「可發現度 D1–D3」抽 D1 或 D2；通過「可達性驗證」
5. 抽枝鑰 ×1–2（D2–D3）、極鑰 ×1（D3–D4，通常是情緒、關係或身體類）
6. 計算威力預算：
     P = 本源基礎值 × 顯化係數
     E = 主鑰易用度（越容易達成，越扣預算）
     C = 代價折讓（代價越重，可以獲得越多威力）
     要求：P − E + C 落在 [90, 110] 之間，否則重新抽代價或調整數值
7. 抽徵兆 ×3–5（依規則覆蓋本源與鑰類），決定是否加入一條假線索
8. 指定真名（從亡獸名錄中，依本源抽取）
9. 隊伍驗證：
     - 同一隊伍中不重複本源
     - 至少存在一組可共鳴的異能組合
     - 「空白者」每隊最多一位
10. 輸出：異能資料（隱藏）＋ 徵兆排程（交給敘事導演）
```

> 組合空間：20 本源 × 平均 4 種相容顯化 × 約 40 鑰的排列 × 12 代價，扣除不相容組合後仍超過十萬種。再加上逆鑰與雙生異能，玩家幾乎不可能遇到兩次一樣的異能。

## 4. 發現的五個層次

| 層 | 名稱 | 條件 | 解鎖 | 演出 |
|---|---|---|---|---|
| L0 | **萌** | 交融波後自動 | 只有徵兆 | 異樣出現在手札裡 |
| L1 | **顯** | 第一次正確觸發主鑰 | 基本型態 | **定格句＋章回標題**，例如「第二章　門把上的雷」 |
| L2 | **熟** | 使用累積（約 15–25 次） | 射程、精度、持續時間提升，解鎖「微操」 | 手札：「我開始能控制它了」 |
| L3 | **枝** | 發現枝鑰 | 分支型態（每個異能有 2–3 個分支，取決於你找到哪一把枝鑰） | 定格句 |
| L4 | **極** | 發現極鑰（通常需要戲劇性的情境） | 極限型態（強大，代價也加倍） | 慢動作過場、專屬音樂 |
| L5 | **名** | 得知真名 | 被動效果、代價減輕 | 亡獸的幻影在身後出現一次 |

**設計目標數據**：L1 的中位數發現時間是 8–20 分鐘；第三幕結束前有 50% 玩家達到 L3；全局平均解鎖度 55–70%（永遠留下沒發現的東西）；只有約 5% 的局能達到 L5。

## 5. 勤務手冊：知識鎖的介面

勤務手冊是每個警校生都有的隨身筆記本。在遊戲中，它是異能系統的主要介面。

### 5.1 自動記錄的「異樣」

> **07:58**　門把又電了我一下，今天第三次。只有我被電，其他人都沒事。
> **08:31**　我屏住呼吸的時候，耳朵裡那個嗡嗡聲不見了。
> **09:05**　無線電在我身邊一直沙沙響，豆漿說他那台沒事。

### 5.2 推論與驗證

- 玩家可以在每條異樣旁邊貼上「推論標籤」（本源標籤＋鑰類標籤），例如 `□雷 □聲 □心　□屏息 □觸碰金屬`。
- 推論標籤**不會**直接告訴你對錯（否則就變成猜謎），但它會提醒你：「試試看在屏息時觸碰金屬？」
- 真正觸發之後，該條紀錄會被蓋上紅色的「**確認**」印章（警察公文印章的質感）。

### 5.3 隊伍頁

- 隊友可以把自己的異樣「分享」到隊伍頁。
- 隊伍頁有「共鳴錄」：記錄發現過的共鳴組合。

## 6. 線索管道與提示階梯

### 6.1 十種線索來源

1. **身體徵兆**：環境中的即時反應。
2. **勤務手冊**：自動記錄。
3. **他人觀察**：NPC 和隊友看到的你（隊友看得到你身上的特效，你自己有時看不到）。
4. **鑑識測試艙**：鑑識大樓的受控實驗室，由林知夏操作。可以把你放進黑暗、水中、低溫、噪音等環境中測試，就像一個解謎小遊戲。
5. **圖書館「那本不存在的書」**：一本作者是你自己的書，用謎語描述你的異能。
6. **同源異獸**：和你真名相同來源的異獸會對你產生反應，例如雷獸會在你面前低頭。
7. **夢境**：在喘息期睡覺時，會夢到亡獸生前的片段，裡面藏著鑰匙的暗示。
8. **時間線殘響**：過去的你留下的筆記（如果你過去抽過同本源的異能）。
9. **白澤**：取得牠的信任後，牠會直接說出一把鑰匙。
10. **其他覺醒者**：同本源的 NPC 可以當你的導師。

### 6.2 提示階梯（保證不卡死，但不破壞驚喜）

| 時間（交融波後） | 若尚未達到 L1 |
|---|---|
| 15 分鐘 | 徵兆頻率提高，手札出現更直接的描述 |
| 25 分鐘 | 敘事導演**安排一個自然觸發主鑰的情境**，例如主鑰是「下雨」就下一場雨，主鑰是「黑暗」就停電，主鑰是「流血」就安排一次擦傷 |
| 40 分鐘 | 一位 NPC 明確說出提示：「我覺得……你好像每次屏住呼吸的時候……」 |
| 輔助選項 | 「提示強度」可調整為：純粹／標準／輔助。輔助模式會在 10 分鐘後直接標示鑰匙類別 |

## 7. 代價、失控與異化

### 7.1 失控（Overdrive）

- 異能使用超過負荷線時，可以選擇「**強行爆發**」：威力 ×3，但無法控制方向，可能傷到隊友和 NPC。
- 失控後，看到的 NPC 信任會下降（「他會不會有一天也這樣對我們？」）。
- 敘事導演會在絕境時提供失控的機會，因為那是最有戲劇性的時刻。

### 7.2 異化（Corruption）

- 疊合率越高、使用異能越頻繁，「異化值」就會越高。
- **外觀變化**：眼睛出現琥珀色光澤、皮膚浮現墨色紋理、聲音帶著回音。
- **好處**：蟲群的信息素偵測會把你當成同類（可以潛行穿過蟲群）。
- **壞處**：國境系的查驗會把你標記為「可疑」，常人派系會排斥你，NPC 恐懼上升。
- **終局**：異化值滿了就會進入「異化結局」，但這不一定是壞結局（見 `05`）。

## 8. 共鳴：隊伍的拼圖

### 8.1 規則

- 異能帶有**物理標籤**（水、電、熱、寒、風、重、聲、光、影、生……），兩個異能的效果交會時，依標籤規則產生共鳴。
- 有些共鳴需要「**共鳴鑰**」：兩個人在同一時間做出各自的鑰匙動作，例如背靠背加上同時敬禮。這是多人版的知識鎖。

### 8.2 共鳴範例

| 組合 | 共鳴名 | 效果 |
|---|---|---|
| 懸雨（水）＋ 逆雷（雷） | **雷雨陣** | 懸停的雨滴帶電，變成一整片空中地雷 |
| 熔掌（熱）＋ 寒系 | **蒸汽爆** | 大範圍擊退＋視線遮蔽 |
| 對調（界）＋ 墜星（重） | **流星換位** | 把隊友換到高處，隊友落地時產生衝擊波 |
| 哨令（聲）＋ 八方心（心） | **百獸令** | 附近的異變動物短暫聽從指揮 |
| 荊血（木）＋ 熔掌（熱） | **火荊** | 燃燒的荊棘牆 |
| 物憶（憶）＋ 擲幣（數） | **殘影預言** | 看見五秒後的殘影 |
| 警徽（契）＋ 哨令（聲） | **全域定身** | 定身範圍擴大到整個據點 |
| 風系 ＋ 熱系 | **火旋** | 移動的火龍捲 |
| 光系 ＋ 影系 | **日蝕** | 一塊完全黑暗的區域，讓趨光蟲與盲蟲同時迷失 |
| 水系 ＋ 寒系 | **冰橋** | 跨越巢苔或斷崖的冰路 |
| 聲系 ＋ 心系 | **群思竊聽** | 短暫聽見群思的下一步計畫 |
| 生系 ＋ 血系 | **換血** | 把一位隊友的傷勢轉移給自己並加速治癒 |

## 9. 範例異能卡（13 張）

> 格式：**名稱**（本源×顯化）｜稀有度
> 徵兆／主鑰／枝鑰／極鑰／代價／真名／設計筆記

---

### ① 懸雨（水×御）｜普通
- **徵兆**：下雨時異常清醒；水面上的倒影會比你早一步眨眼；杯裡的水在你屏息時不再晃動。
- **主鑰**：在雨中（或水邊）**屏息** → 半徑 5 公尺內的雨滴懸停在空中，蟲穿過會被減速。
- **枝鑰 A**：懸停時**敬禮** → 雨滴排成陣列，化為水彈齊射。
- **枝鑰 B**：懸停時**拍手** → 雨滴聚成一面水盾。
- **極鑰**：**流血時**屏息 → 你的血也會懸停（可以止血，或凝成血刃）。
- **代價**：聽覺。每次使用後 3 秒完全無聲。
- **真名**：蒼淵「**雨師**」最後的一口氣。
- **筆記**：主鑰依賴雨，所以導演一定會安排雨。這張卡適合作為新手教學範例。

### ② 逆雷（雷×放）｜普通
- **徵兆**：門把一直電你；手錶停了；你一靠近，無線電雜訊就變大。
- **主鑰**：**屏息並觸碰金屬** → 金屬導雷，碰到它的蟲會被電擊（門把、欄杆、鐵捲門都可以變成陷阱）。
- **枝鑰 A**：**敬禮** → 指尖射出可以瞄準的雷弧。
- **枝鑰 B**：**站在雨中** → 範圍型落雷。
- **極鑰**：**心跳超過 160**（奔跑或極度恐懼後） → 身體雷化，短時間內以雷速移動。
- **代價**：電子。你周圍 10 公尺內的無線電、手電筒、手機會故障，連隊友的也會。
- **真名**：蒼淵雷獸「**夔**」。
- **筆記**：序章試寫（`10`）的主角就是這張卡。

### ③ 物憶（憶×感）｜傳說
- **徵兆**：摸到某些東西時，腦中閃過不屬於你的畫面；你常常覺得「這裡發生過什麼事」。
- **主鑰**：**觸碰物品並閉眼三秒** → 看見這個物品最後五分鐘的殘影（例如被擄走的同學最後去了哪裡）。
- **枝鑰 A**：**觸碰蟲屍** → 看見這隻蟲回巢的路線（直接找到繭池）。
- **枝鑰 B**：**觸碰一個人** → 看見他最近的謊言。
- **極鑰**：**觸碰自己的倒影** → 看見另一條時間線的自己（取得一則時間線殘響）。
- **代價**：記憶。地圖標記一個一個消失。
- **真名**：蒼淵「**白鏡獸**」。
- **筆記**：鑑識系玩家抽到時，會有專屬對話：「這不就是我們上課在學的嗎……只是更直接。」

### ④ 墜星（重×化）｜普通
- **徵兆**：東西在你手邊掉得比較慢；你跳得比別人高；體重計顯示的數字會跳動。
- **主鑰**：**從高處跳下時保持蹲姿** → 落地時產生衝擊波，不受摔落傷害。
- **枝鑰 A**：**與隊友背靠背** → 兩人共享低重力，可以大跳。
- **枝鑰 B**：**握拳數到十** → 讓手中的物體變得極重，可以投擲出巨大的衝擊力。
- **極鑰**：**恐懼值滿** → 你周圍的局部重力反轉，蟲群往天上掉。
- **代價**：體力。
- **真名**：蒼淵「**負嶽**」。

### ⑤ 哨令（聲×域）｜普通
- **徵兆**：聽得到牆後的對話；你吹口哨時，鳥群會集體轉頭。
- **主鑰**：**吹口哨** → 半徑 15 公尺內的蟲群陷入混亂（第一層：混亂；誤用時反而會吸引牠們）。
- **枝鑰 A**：**使用警哨（物品）** → 範圍擴大三倍，可以引導蟲群移動。
- **枝鑰 B**：**閉眼吹口哨** → 回聲定位，看穿牆壁。
- **極鑰**：**唱起校歌** → 讓 NPC 免疫恐懼的士氣場（還有彩蛋：在熄燈號播放時唱歌……）。
- **代價**：噪音。會吸引哨翅。
- **真名**：蒼淵鳴鳥「**鵸鵌**」。

### ⑥ 熔掌（熱×附）｜普通
- **徵兆**：手心總是很燙；冰塊在你手裡融化得特別快。
- **主鑰**：**握拳數到十** → 手中的金屬物燒得通紅（灼熱警棍、灼熱消防斧）。
- **枝鑰 A**：**站在火旁** → 子彈附帶熱能（需要先觸碰彈匣）。
- **枝鑰 B**：**憤怒**（剛看到同伴受傷）→ 整隻手臂熔化成岩漿狀的拳套。
- **極鑰**：**體溫過低時**握拳 → 熱量逆流，大範圍爆炎（「寒極生熱」）。
- **代價**：飽食與口渴。
- **真名**：蒼淵火鳥「**畢方**」。
- **筆記**：消防系玩家權重 ×1.3。

### ⑦ 對調（界×換）｜罕見
- **徵兆**：偶爾一眨眼就站在半步之外；鏡子裡的你會延遲。
- **主鑰**：**看著某人並連續眨眼兩次**（按兩下特定鍵）→ 與對方交換位置（最強的救援技）。
- **枝鑰 A**：**看著一隻蟲** → 與蟲交換位置。
- **枝鑰 B**：**觸碰物品後看向遠處** → 把物品「寄」到視線所及之處。
- **極鑰**：**有人陷入危險時** → 一次與最多三人連鎖交換。
- **代價**：記憶。被你交換的人會短暫忘記你是誰（對話會變成「你……是誰？」）。
- **真名**：蒼淵「**雙生狐**」。

### ⑧ 八方心（心×感）｜罕見
- **徵兆**：聽見他人的心跳；動物特別親近你；小八只聽你的話。
- **主鑰**：**撫摸動物** → 共享這隻動物的感官（以小八的鼻子嗅出擬態蟲、以烏鴉的眼睛偵察）。
- **枝鑰 A**：**與隊友牽手** → 共享對方的視野，跨越整張地圖。
- **枝鑰 B**：**閉眼** → 看見附近所有生物的「心跳光點」。
- **極鑰**：**觸碰一隻活著的蟲** → 與群思共感，聽見蟲族的聲音（危險：理智大量下降。這條路通往「對話結局」）。
- **代價**：理智，以及他人代價（共感對象的壓力也會上升）。
- **真名**：蒼淵「**萬靈犀**」。

### ⑨ 荊血（木×召）｜普通
- **徵兆**：你經過的草長得比較快；花朝你的方向轉；你流血時，地上的螞蟻會繞開。
- **主鑰**：**讓血滴到泥土上** → 長出一面荊棘牆（需要流血，所以搭配自傷或受傷）。
- **枝鑰 A**：**雙手合十** → 荊棘開花，花粉讓蝕蝨迷向。
- **枝鑰 B**：**在月光下** → 荊棘會自動攻擊。
- **極鑰**：**飢餓時** → 召出一株巨樹，成為臨時據點。
- **代價**：飢餓。
- **真名**：蒼淵「**建木之芽**」。

### ⑩ 擲幣（數×感）｜傳說
- **徵兆**：擲硬幣總是正面；你上次統一發票對中了兩百塊（一個小彩蛋）。
- **主鑰**：**擲硬幣**（肢體輪盤動作，需持有硬幣）→ 正面：下一次攻擊必定命中弱點；背面：預見下一個 30 秒內的危險方向。
- **枝鑰 A**：**對著同伴擲** → 結果作用於對方。
- **枝鑰 B**：**閉眼擲** → 選擇正面或背面（但代價加倍）。
- **極鑰**：**連續擲出七次正面** → 改寫一個已發生事件的結果（例如讓一位剛殉職的同學「其實只是昏迷」）。一局只能使用一次。
- **代價**：幸運反噬。
- **真名**：蒼淵「**命骰龜**」。

### ⑪ 警徽（契×域）｜傳說・本作招牌
- **徵兆**：你說出口的命令，別人總是不自覺地照做；你的警徽在黑暗中會微微發亮。
- **主鑰**：**亮出警徽並大喊「警察！不要動！」**（肢體輪盤加上指令；選配麥克風語音辨識）→ 半徑 10 公尺內所有生物（包括蟲）僵直 1.5 秒。
- **枝鑰 A**：**宣讀權利**（「你有權保持緘默……」）→ 對人類暴民：完全解除武裝。
- **枝鑰 B**：**敬禮** → 定身時間延長，並且對 Boss 有效。
- **極鑰**：**熄燈號播放時** → 「**法即是界**」：一個持續 30 秒、蟲無法進入的領域。
- **代價**：誓約。你必須「像個警察」：如果你逃跑而拋下平民、說謊，或濫殺被寄生但仍可救治的人，異能就會失效，直到你做出一次真正的救援來贖回它。
- **真名**：蒼淵「**獬豸**」（傳說中能辨是非曲直的神獸，也是法律的象徵）。
- **筆記**：警察學校的意念加上獬豸的天賦。這是只有在這座學院才可能出現的異能。

### ⑫ 影步（影×化）｜普通
- **徵兆**：你的影子偶爾比你慢半拍；黑暗的房間讓你覺得安心。
- **主鑰**：**站在陰影中閉眼三秒** → 融入陰影，可以在相連的陰影之間移動。
- **枝鑰 A**：**停止說話**（逆鑰；語音模式下要真的靜音）→ 影化時完全無聲。
- **枝鑰 B**：**觸碰隊友的影子** → 把隊友一起帶進陰影。
- **極鑰**：**日蝕或停電時** → 所有影子都是你的通道。
- **代價**：光敏。日光下會頭暈並持續受傷。
- **真名**：蒼淵「**夜行狸**」。

### ⑬ 空白（無）｜特殊（3%）
- **徵兆**：沒有。完全沒有。其他人都覺醒了，只有你什麼也沒有。
- **真相**：你是「**錨點**」。你對所有異能效果和群思的精神干擾都免疫，擬態蟲騙不了你，寄生在你身上也會失敗。
- **鑰**：沒有鑰匙。但你會在遊戲中慢慢發現，你是唯一可以走進母巢核心而不被同化的人。
- **代價**：孤獨。常人派系會把你當成自己人，覺醒者派系會輕視你。
- **結局**：解鎖「錨點結局」。
- **筆記**：這是對「我是不是被系統放生了？」的焦慮所設計的反轉。結算報告在揭曉時會寫：「你什麼都沒有。所以牠們什麼都拿不走。」

## 10. 特殊變體

| 變體 | 機率 | 說明 |
|---|---|---|
| **逆鑰異能** | 8% | 主鑰是「停止」某件事 |
| **雙生異能** | 2%（只在多人模式） | 兩位玩家的異能是同一隻亡獸天賦的兩半。必須在 20 公尺內才能使用，合在一起時威力是單人的四倍。結算時會一起揭曉：「你們是同一個靈魂的兩半。」 |
| **遲來者** | 5% | 異能要到第二夜才會萌芽（劇情理由：天賦還在尋找你）。在那之前，你就是一個常人 |
| **NPC 轉移** | 事件觸發 | 某些 NPC 死去時，他的天賦會選擇轉移到你身上（你同時擁有兩個異能，第二個的徵兆從零開始） |

## 11. 平衡與遙測

- **威力預算**：所有異能落在 90–110 的預算區間內。
- **遙測指標**：L1 發現時間、各層達成率、鑰匙觸發失敗次數（判斷是否太隱晦）、代價承受率（玩家是否因為代價太重而放棄使用）。
- **調整原則**：鑰匙太難發現就增加徵兆，不要降低鑰匙難度；異能太弱就減輕代價，不要直接加威力。保持「知道就很強」的爽快感。
