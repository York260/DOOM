# v2-04　連線與生存日誌

## 1. 連線規格

| 項目 | 內容 |
|---|---|
| 人數 | 1–4 人合作（單人時，室友豆漿和兩位 AI 夥伴會跟著你） |
| 架構 | 主機－客戶端（一位玩家當主機），Steam 好友邀請或房間代碼 |
| 中途加入 | 可以。新加入的人以「躲在器材室裡的志工」身分出現 |
| 中途離開 | 角色變成 AI 夥伴；回來時可以接回 |
| 存檔 | 每天早上自動存檔。下次同一群人回來，從那一天早上繼續 |
| 重生 | 全隊一起重生，每個人都帶著自己的記憶 |

## 2. 為什麼這個設計適合和朋友玩

- **操作簡單**：不常玩遊戲的朋友也能三十秒上手。
- **每個人的異能都不一樣，而且連自己都不知道**：「欸，你走到水邊的時候，按鈕是不是有發光？」溝通本身就是玩法。
- **自然的分工**：誰的異能適合守門、誰適合出去搜刮、誰適合種田，每一輪都不同。
- **共鳴**：兩個人一起按，會發生意想不到的事（見 `02` §4）。
- **頓悟是全隊的事**：任何一個人頓悟時，全隊的畫面都會一起定格。

## 3. 倒地與失敗

```text
血量歸零 → 倒地
  ├─ 隊友用急救包救起 → 繼續
  ├─ 隊友把你扛回據點 → 在醫護站復原
  └─ 沒人來救，直到這個白天或夜晚結束
       → 下一個早晨在據點醒來，但背包裡的東西掉在原地
全隊同時倒地，或者蟲衝進避難室 → 這一輪結束 → 結算 → 重生
```

不會有人「死掉之後只能在旁邊看」。最壞的情況，就是等到下一個早晨。

## 4. 生存日誌

> 生存日誌是本作的敘事層：一本每天早上自動寫下的日記，用小說的筆法記下昨天發生的事。

### 4.1 每天早上的一頁

- 三到五句話，由事件記錄自動組合而成。
- 內容包括：昨天最重要的一件事、資源的變化、某位夥伴的一句話、一個伏筆。
- 選了「中文」主修的玩家，日誌會多寫一句關於異能條件的提示。

**範例**：

> **第四天**
> 昨天許安讓整座游泳池結了冰。蟲過不了水，他第一次笑了。
> 泡麵還剩十一包，發電機的油夠撐兩晚。
> 陳硯說：「明天我去醫院。我一個人去就好。」
> 晚上的時候，排水口裡有東西在敲。

### 4.2 記憶頁

生存日誌的最後幾頁是「記憶頁」，自動記錄你親眼見過的事實（見 `01` §8）。重生之後，記憶頁會跟著你。

## 5. 結算報告（每一輪結束時）

沿用 v1 的結算報告，但縮短成一個畫面可以看完的長度：

| 區塊 | 內容 |
|---|---|
| **評級** | 依存活天數、救援人數、異能解鎖度、據點完整度計分。等級以警銜命名：特任、警監、警正、警佐、學員、新生、失聯 |
| **稱號** | 例如「讓雨停下的人」「搬走整間福利社的志工」「第三夜才發現自己會飛的人」 |
| **異能揭曉** | 你這一輪的本源、三個條件、祕密的第四條件、真名。**沒發現的條件也會揭曉，並且告訴你「你其實差一點就做到了」的那一刻** |
| **重要事蹟** | 五件事，依時間排列 |
| **倖存者的評價** | 三位夥伴的一句話 |
| **蟲族的評價** | 群思的學習紀錄：「樣本 07-一。牠讓水停下。我們學會在雨停之前到達。」 |
| **後續** | 一小段開放式的結尾 |
| **給下一輪的記憶** | 自己寫一句話（30 字以內），它會出現在下一輪的某個角落（塗鴉、紙條、廣播雜訊） |

**異能揭曉範例**：

```text
逆雷（雷）　真名：蒼淵雷獸「夔」
✔ 碰到金屬　　→ 導雷（D1 13:05）
✔ 在雨中　　　→ 連鎖閃電（D2 10:40）
✘ 在發電機旁　→ 充電
✘ 祕密條件：剛衝刺完、心跳最快時
你其實差一點：D3 夜晚，你衝回據點時就站在發電機旁。你按的是互動鍵。
```

## 6. 選配模式

| 模式 | 內容 |
|---|---|
| 三夜模式 | 約 35 分鐘的短版 |
| 每週同一天 | 全球玩家玩同一條時間線（相同種子），比較結局 |
| 寄生者（3–4 人） | 一位玩家在第二夜被寄生，暗中替蟲族做事。可以被救回來 |
| 聲紋偵測 | 麥克風太大聲，遊戲裡的蟲會聽見 |
