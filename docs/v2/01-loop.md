# v2-01　一輪的流程

## 1. 時間表

| 階段 | 遊戲內時間 | 實際時間 | 玩家在做什麼 |
|---|---|---|---|
| **前夜** | D1 07:30–12:00 | 約 10 分鐘 | 囤貨、選據點、說服夥伴、觀察異兆 |
| **交融波** | D1 12:00 | 約 1 分鐘 | 過場；異能鍵亮起；第一批小蟲出現 |
| **第一天下午** | D1 12:00–18:00 | 約 5 分鐘 | 把人和物資帶回據點 |
| **第 1–7 夜** | 每天 18:00–06:00 | 每夜約 4 分鐘 | 守住據點 |
| **第 2–7 天** | 每天 06:00–18:00 | 每天約 5 分鐘 | 出去搜刮、救人、找異能條件 |
| **早晨** | 每天 06:00 | 約 1 分鐘 | 生存日誌、分配夥伴、蓋建設 |
| **第七夜** | D7 18:00– | 約 8 分鐘 | 天裂，Boss |
| **結算** | — | 約 2 分鐘 | 結算報告、寫下給下一輪的記憶 |

一輪完整通關約 70–80 分鐘。多數玩家的第一輪會在第二或第三夜結束（約 25–35 分鐘），這是刻意的設計：第一輪的任務是「看見」，第二輪才開始「準備」。

**三夜模式**：把七天壓縮成三天三夜（第三夜就是 Boss），約 35 分鐘，適合平日晚上。

## 2. 前夜：日常被打破之前

### 2.1 第一輪：你什麼都不知道

第一輪沒有倒數計時。玩家以為自己在玩一個「防災演習」的開場，演習流程就是新手教學：

| 時間 | 演習項目 | 實際上在教什麼 |
|---|---|---|
| 07:30 | 報到、抽演習角色卡 | 移動、互動、和 NPC 說話 |
| 08:00 | 演習說明（區隊長嚴振東） | 認識地圖上的地標 |
| 08:30 | 疏散演練：把「傷患」抬到集合點 | **搬運**（兩人合抬、推車） |
| 09:30 | 消防演練：滅火器 | 道具的使用 |
| 10:30 | 封鎖演練：架設拒馬、封住門口 | **據點插槽**（防線怎麼蓋） |
| 11:30 | 午餐、自由時間 | 自由探索、福利社 |
| 11:50 | 異兆：鳥群繞圈、手機沒訊號、門把電人 | 觀察 |
| 12:00 | 演習警報準時響起。然後天空裂開了 | — |

第一輪的異兆裡，藏著你這一輪異能的線索（例如「門把一直電你」）。但大多數玩家第一次不會注意到。

### 2.2 第二輪以後：你記得

醒來的那一刻，畫面上出現倒數：**距離交融波　04:30:00**。

這時前夜變成一場和時間賽跑的囤貨：

| 你可以做的事 | 怎麼做 | 代價 |
|---|---|---|
| **囤貨** | 福利社、餐廳、健康中心、演習器材區、駕訓場的油料 | 背包只有六格；大型物資要用推車或兩人合抬 |
| **選據點、先蓋防線** | 把拒馬、木板、滅火器先搬進你選的建築 | 會被演習人員問「你在幹嘛？」 |
| **說服夥伴** | 用「預言」：告訴 NPC 一件馬上要發生的事（例如「十點十五分會停電一次」），發生之後他就會相信你 | 預言錯了，他會覺得你是怪人 |
| **拿到械彈庫的鑰匙** | 說服區隊長，或者找到傳說中的第三把鑰匙 | 失敗的話會被盯上 |
| **救更多人** | 交融波前把人帶到安全的地方 | 需要理由，沒人想錯過午餐 |
| **探索祕密** | 校史館、後山、圖書館地下書庫 | 花時間 |

**可疑度**：你在演習日做了太多奇怪的事（搬走整箱泡麵、闖進管制區、到處說中午會世界末日），可疑度會上升。滿了就會被帶到保健室「休息」，要浪費三十分鐘才能出來。這讓囤貨有一點潛行和社交的味道，但規則只有一條，很好懂。

### 2.3 前夜帶進據點的東西，就是你的起始資源

交融波發生時，已經在據點裡的物資會直接變成你的起始「糧、電、材」；已經在據點裡的夥伴不會昏倒在外面。這是第二輪以後最直接的爽感：**「這一次，我們準備好了。」**

## 3. 交融波（12:00）

- 所有聲音消失一秒，天空像墨滴在宣紙上一樣暈開。
- 大約一半的 NPC 倒下（每輪不同的人）。
- 每位玩家畫面右下角的異能鍵亮起，上面只有一個「？」。
- 排水溝裡湧出第一批拇指大小的蟲（蝕蝨）。
- 區隊長的聲音從廣播裡傳出來：「這不是演習。」

## 4. 白天：出去

### 4.1 地圖

- 校園分成六個區（宿舍區、教學區、行政區、運動區、訓練區、後山），每區約一兩分鐘就能走完。
- 第三天以後，透過事件解鎖校外的「遠征地點」：雲台鎮老街、長青醫院、化工廠。需要開車（駕訓場的車），引擎聲會吸引蟲。
- **巢苔**每天從裂隙往外擴散一區。被巢苔覆蓋的區域會變紅：蟲更多，物資也更好。

### 4.2 地圖上只有四種標記

| 標記 | 意思 |
|---|---|
| 黃色箱子 | 物資 |
| 紅色求救 | 有人受困，旁邊有倒數（過了就沒了） |
| 紫色漣漪 | 異常：傳說地點、異化物品、隨機事件 |
| 你的異能鍵在發光 | 你接近了某個隱藏條件（見 `02`） |

### 4.3 黃昏鐘

天黑前 30 秒，鐘樓會響。來得及就回家；來不及就要在外面撐過一夜（危險，但夜裡的物資特別好）。

## 5. 夜晚：守住

- 蟲會分兩到三波攻擊據點的各個入口。
- 玩家站在防線後面戰鬥，用異能，修補被打破的門窗。
- 最後一波最大，通常就是放大招的時候。
- 每一夜都有**一種新的威脅**（見 `03` §5）。

## 6. 早晨：喘口氣

每天早上約一分鐘，只做三件事：

1. **讀生存日誌**：一頁小說般的文字，總結昨天（見 `04` §4）。
2. **分配夥伴**：把救回來的人分派到守衛、廚師、農夫、工程、醫護、斥候。
3. **蓋建設**：從隨機抽出的三張建設卡中免費選一張，也可以花「材」蓋其他的。

## 7. 失敗與重生

### 7.1 什麼時候會失敗

- 全隊同時倒地；或
- 蟲衝進據點最裡面的「避難室」（那裡是倖存者躲的地方）。

### 7.2 重生

- 結算報告之後，畫面淡出。你在 07:30 的雲台大學校車上醒來，手機上的鬧鐘還在響。
- **你保留**：記憶（見 §8）、圖鑑、異能語法（你見過哪些本源和條件類型）。
- **你不保留**：物資、據點、夥伴的信任，以及你的異能（每一輪重抽，因為每一次交融都是一個新的平行時空）。

## 8. 記憶系統

### 8.1 記憶頁

遊戲會自動把你親眼見過的「事實」記到生存日誌的記憶頁裡，例如：

- 「10:15，行政大樓會停電一次，大約五分鐘。」
- 「福利社後門的密碼是 0742。」
- 「13:40，拾骸者會從游泳池的排水口爬出來。」
- 「區隊長的女兒今天生日。他只要聽到這件事，就會相信你。」
- 「哨翅怕煙。」

下一輪，這些記憶可以直接拿來用：說服 NPC、打開保險箱、提前在對的地方設陷阱。

### 8.2 記憶會出錯

每一輪都是平行時空。交融波之前大部分的事會照記憶發生；交融波之後，越往後越不一樣。記憶錯了的時候，記憶頁上那一條會被劃掉，旁邊寫上：**「這一輪不一樣。」**

| 時段 | 記憶的可靠度 |
|---|---|
| 前夜 | 約 80% |
| 第 1–2 天 | 約 65% |
| 第 3–4 天 | 約 50% |
| 第 5–7 天 | 約 35% |

這讓記憶成為優勢，但不會讓遊戲被背熟。

### 8.3 真相與破除輪迴

- 每一輪都可能發現「真相碎片」：1972 年的小疊合、熄燈號為什麼不能停、校史館的黑鐵印（沿用 v1 的真相層）。
- 集滿碎片之後，前夜會出現一個新的選項：在 12:00 之前，阻止交融波本身。這就是「破除輪迴」的結局。

## 9. 一輪範例：第三輪

> 以下示範第三輪可能發生的事，用來說明「操作很簡單，但過程很多變」。

- **07:30**　Mika 抽到黑票「罹難者」，凌宇抽到媒體記者，老K 是鬧事民眾。三個人都記得上一輪死在第二夜。
- **08:10**　凌宇對區隊長說：「十點十五分，行政大樓會停電。」區隊長沒理他。
- **10:15**　停電了。區隊長看著凌宇看了很久，把械彈庫的一把鑰匙交給了他。
- **11:20**　老K 用福利社的推車搬走了兩箱泡麵和一台發電機。可疑度八成。
- **12:00**　交融波。這一輪的主裂隙開在游泳池上方，和前兩輪都不一樣。
- **12:01**　Mika 的異能鍵上出現「？」。她按了一下，身體變得半透明了一秒。
- **D1 下午**　他們選了射擊館當據點。只有一個出口，但牆夠厚。
- **D2 白天**　暴雨。Mika 發現她站在屋簷的陰影下時，異能鍵在發光。她躲進陰影按下去，人消失了，下一秒出現在十公尺外另一片陰影裡。畫面定格：「原來你一直都住在影子裡。」
- **D3 夜晚**　穿岩之夜。蟲從射擊館的地板下鑽上來。他們這才知道，射擊館唯一的弱點在腳下。
- **D4 白天**　救回警校新生許安。他的異能讓整座游泳池結冰，蟲過不了水了。
- **D5 夜晚**　群思適應：牠們學會了繞開老K 一直用的電網。老K 把電網拆了，改種驅蟲草。
- **D6 早晨**　生存日誌：「第六天。泡麵還剩十一包。許安終於敢一個人站哨了。」
- **D7 夜晚**　Boss 是鏡后。她複製了 Mika 的影步，但 Mika 知道影步在強光下會失效。凌宇打開了射擊館所有的燈。
- **D8 07:30**　他們活下來了。結算報告的最後一句是：「但校車上，沒有人記得今天要演習。」
