# v2-00　重新定位

> v2 把整款遊戲收斂成一句話：**上手三十秒，每一輪都不一樣，爽點只有兩個：異能和活下去。**
> v1 的世界觀（鷹嶺警官學院、蒼淵、蝕群、熄燈號）大部分保留；玩法從「重度 3D 開放世界」改成「簡單操作、高變化」的合作生存。

## 1. 一句話

> **你只是來警察大學當演習志工的普通大學生。中午十二點，天會裂開。你知道，因為你已經死過一次。**

## 2. 和 v1 相比，改了什麼

| 項目 | v1 | v2 | 為什麼 |
|---|---|---|---|
| 主角 | 警校生 | **一般大學生**，到警大擔任防災演習的志工 | 外人視角：校園本身就是未知；警校生成為可靠的夥伴 |
| 時間起點 | 交融波當天早上 | **交融波前四個半小時**，從報到開始 | 讓「日常被打破前」可以玩，而且是囤貨的黃金時間 |
| 失敗 | 一局結束 | **重生回 07:30，帶著記憶** | 參考《Survival Log》的重生機制；知識就是進度 |
| 視角 | 第三人稱肩後 | **斜 45 度俯視角 3D** | 操作簡單、蟲潮看得清楚、多人好協調 |
| 操作 | 移動、射擊、肢體輪盤 12 個動作 | **三顆鍵：移動、互動、異能**（自動攻擊） | 極簡 |
| 異能 | 六元件、手勢鑰匙 | **一鍵異能**：同一顆鍵，條件對了威力翻倍；按鈕會「發光」提示你接近條件 | 知識鎖保留，但變成直覺的冷熱遊戲 |
| 生存 | 十多項數值 | **據點四個數字：糧、電、材、人** | 壓力而非家務 |
| 結構 | 72 小時連續、五幕 | **前夜＋七天七夜** | 節奏清楚：白天出去、晚上守家 |
| 一輪長度 | 2.5–3 小時 | **約 70–80 分鐘**（另有 35 分鐘的「三夜模式」） | 朋友晚上約得到 |

## 3. 主角為什麼在警察大學

**設定**：國立鷹嶺警官學院每年舉辦「全民防災演習日」，會向附近的雲台大學招募學生，擔任模擬民眾與傷患（有工讀金和志工時數）。你和幾個朋友一起報名，07:30 到校報到。

這個安排同時解決了五件事：

1. **你是外人**：你不熟悉這座校園，地圖本身就是要探索的未知。
2. **夥伴有分工**：警校生受過訓練、有紀律、拿得到槍；你沒受過訓練，但你身上有最不受控的東西：異能。
3. **演習就是新手教學**：疏散、搬運傷患、架拒馬、用滅火器，全都是第一輪的教學內容，而且玩家不會覺得自己在上課。
4. **演習器材就是囤貨素材**：拒馬、擔架、無線電、滅火器、急救包，早上都已經擺在校園裡。
5. **戲劇反諷**：中午警報響的時候，所有人都以為那是演習的一部分。

> 替代方案：如果你想要「主角就在自己的大學」，可以把雲台大學的校園直接以警大的配置為藍本（射擊館改成體育中心、械彈庫改成校警隊倉庫）。其他設計都不用改。

### 3.1 演習角色卡（每輪隨機，決定開局）

報到時每位志工都會抽到一張演習角色卡。它決定你從哪裡開始、手上有什麼，也是每一輪的第一個變化。

| 角色卡 | 開局位置 | 開局道具 | 特色 |
|---|---|---|---|
| 紅票・重傷患 | 至善堂的擔架上 | 止血帶 | 劇本上你要被抬走。交融波發生時，你正躺著 |
| 黃票・骨折傷患 | 教學區走廊 | 夾板（可以拿來打） | 演習中走路一跛一跛的，交融波後就好了 |
| 綠票・輕傷民眾 | 自由活動 | 背包多兩格 | 最自由的開局 |
| 黑票・罹難者 | 鑑識大樓旁的「停屍區」 | 白布 | 你今天的工作是當屍體。蟲一開始不會注意靜止的你 |
| 媒體記者 | 正門 | 相機（拍蟲可以加速圖鑑） | 可以自由進出管制區 |
| 鬧事民眾 | 升旗廣場 | 擴音器 | 警校生一開始不太信任你；擴音器能放大聲系異能 |

### 3.2 主修（玩家選擇，十選一）

| 主修 | 被動效果 |
|---|---|
| 資工 | 可以駭入電子門、監視器、無人機 |
| 護理 | 救起倒地隊友的速度加倍；醫護站效率提高 |
| 機械 | 自製砲台和陷阱的材料減半 |
| 化工 | 可以調配汽油彈與驅蟲劑 |
| 體育 | 衝刺更久，可以一個人搬重物 |
| 餐飲 | 據點的糧食效率提高 50% |
| 電機 | 發電機效率加倍，可以架電網 |
| 生科 | 作物長得更快，解剖蟲屍可以找出弱點 |
| 戲劇 | 說服 NPC 更容易，可以裝死、演戲引開蟲 |
| 中文 | 生存日誌會多寫一句提示；解讀傳說與古籍更快 |

## 4. 玩法方向提案

| 方案 | 形式 | 優點 | 缺點 |
|---|---|---|---|
| **A. 俯視角合作生存（推薦）** | 斜 45 度 3D、自動攻擊、一鍵異能；白天出去搜刮，晚上守住據點 | 三十秒上手、蟲潮的爽感最直接、多人好協調、未來可以上 Switch 和手機 | 寫實沉浸感較弱 |
| B. 第三人稱動作生存（v1 路線） | 肩後視角、手動瞄準、開放世界 | 沉浸、電影感 | 操作門檻高、開發成本高 |
| C. 日誌式策略生存 | 在地圖上派人、選地點、讀日誌決定下一步 | 最簡單 | 異能的爽感最弱 |

**建議採用 A**，並把 C 的「生存日誌」當成敘事層：每天早上用一頁小說般的日誌，總結昨天發生的事。

## 5. 核心循環

```text
前夜 07:30–12:00（約 10 分鐘）
  囤貨、選據點、說服夥伴、觀察異兆
        │
        ▼
12:00 交融波：半數人倒下，你的異能鍵亮起一個「？」
        │
        ▼
┌──────────── 七天七夜 ────────────┐
│ 白天（約 5 分鐘）：出去搜刮、救人、尋找異能條件 │
│ 夜晚（約 4 分鐘）：蟲潮來襲，守住據點          │
│ 早晨（約 1 分鐘）：生存日誌、分配夥伴、蓋建設   │
└───────────────────────────────────┘
        │
        ▼
第七夜：天裂，Boss
        │
        ▼
結算報告 → 重生回 07:30，帶著這一輪的記憶
```

## 6. 三顆鍵

| 鍵 | 功能 |
|---|---|
| **移動** | 搖桿／WASD／觸控。武器會自動攻擊最近的敵人（PC 可以開啟雙搖桿手動瞄準） |
| **互動** | 依情境自動判斷：撿起、打開、搬運、修理、救人、說服 |
| **異能** | 按一下釋放；按住蓄力。條件對了，效果翻倍 |

沒有技能樹、沒有升級選單、沒有複雜的背包。背包只有六格，裝滿就要決定丟什麼。

## 7. 簡單，但每一輪都不一樣

> 公式：**簡單的操作 × 隨機的組合 × 記憶的累積**

| 變化來源 | 每輪變化 |
|---|---|
| 你的異能 | 16 種本源 × 約 30 種條件，每輪重抽 |
| 演習角色卡 | 6 種開局 |
| 主修 | 10 種（玩家選） |
| 據點 | 5 座建築，各是一張不同的防守地圖 |
| 天氣與災害 | 每天抽一種：停電、暴雨、孢子霧、酷熱、低重力潮汐、斷水…… |
| 夜晚威脅 | 第二到第六夜從威脅池中抽取，順序不同 |
| 裂隙位置 | 主裂隙有五個候選位置，決定蟲從哪裡來 |
| 夥伴 | 誰會覺醒、得到什麼異能、會不會被寄生 |
| 異化物品 | 撿到的東西有 0–2 條隨機詞綴 |
| 校園傳說 | 七大不可思議中隨機啟動三個 |
| Boss | 三位候選，由蟲族依你的打法選出 |

而且**同一天會重複**：每一輪都是同一個演習日，所以記憶有用；但交融之後世界會分歧，所以永遠不會被背熟。前夜大約 80% 會照你記得的發生，到第五天以後只剩一半。

## 8. 兩個爽點

### 爽點一：異能（「原來是這樣！」）
- 每一次發現條件，異能就**當場進化**一次，畫面定格，跳出一句小說般的句子。
- 條件成立時，威力 ×3。玩家會開始「依照自己的異能改變打法」：雷系去淋雨、影系等停電、重力系往高處跳。
- 三個條件都找到之後，還有一個祕密的覺醒條件：清場級的大招。

### 爽點二：生存（「我們撐過來了」）
- 白天決定冒險多深：多搬一台發電機，還是趕在天黑前回家。
- 夜晚看著自己蓋的防線擋住第一波，然後在最後一波時開大招。
- 早上的生存日誌告訴你：昨晚又多活了一天、多救了三個人。

## 9. 參考與差異

本版的兩段式結構與重生機制，參考了 2026 年 8 月上市的《Survival Log》：末日前倒數囤貨、強化自宅，末日後經營據點、應對停電與天候災害、救助鄰居，並在失敗後帶著記憶重生。

| 借用的概念 | 本作的延伸 |
|---|---|
| 末日前的倒數囤貨 | 「前夜」：在警大的演習日裡囤貨、選據點；第一輪是教學，之後才有倒數 |
| 末日後的據點經營 | 簡化成四個數字和插槽式防線，重點放在夜晚的蟲潮守城 |
| 停電、天候災害 | 災害會和異能條件連動：暴雨可能是雷系的福音，也可能是火系的災難 |
| 救助鄰居、建立社群 | 救下的警校生和志工會成為夥伴，他們也有隱藏的異能 |
| 帶著記憶重生 | 記憶有用但不可靠：交融之後世界會分歧；每一輪的異能也會重抽 |
| — | 新增：1–4 人合作、俯視角動作戰鬥、一鍵異能 |

> 註：以上對《Survival Log》的描述，來自其 Steam 商店頁的公開介紹。
