# v2-03　生存與據點

## 1. 原則

> 生存是壓力，不是家務。玩家只需要看懂四個數字，就能做出有意義的決定。

## 2. 玩家自己：只有兩條

| 數值 | 說明 |
|---|---|
| 血 | 歸零就倒地。隊友可以把你扛回據點，或用急救包當場救起 |
| 體力 | 只影響衝刺。搬重物時不能衝刺 |

飢餓、口渴、睡眠全部交給據點處理。玩家在外面時，不用分心照顧自己。

## 3. 據點：四個數字

| 數字 | 來源 | 消耗 | 不夠的時候 |
|---|---|---|---|
| **糧** | 搜刮、菜園、廚房 | 每人每天 1 | 夥伴生病或離開 |
| **電** | 油料、發電機、雷系異能 | 夜裡的燈、電網、砲台 | 停電：燈和電網全部失效 |
| **材** | 木板、鐵件、家具、廢棄車輛 | 蓋防線、蓋設施 | 防線修不好 |
| **人** | 救回來的夥伴 | 每人吃 1 糧 | — |

每天早上，系統自動結算消耗，並在生存日誌中寫一句結果，例如：「泡麵還剩十一包。」

## 4. 據點的選擇（五座，各是一張防守地圖）

| 據點 | 入口 | 優點 | 弱點 | 適合的異能 |
|---|---|---|---|---|
| **射擊館** | 1 個正門＋地板 | 牆最厚、隔音（夜晚吸引的蟲較少）、靠近械彈庫 | 只有一個出口；地板下有空洞 | 雷（鐵捲門導雷）、聲 |
| **綜合體育館** | 2 個門＋屋頂天窗 | 空間最大，可收容最多夥伴 | 屋頂薄，哨翅會從天窗下來 | 重（從看台跳下）、風 |
| **守四舍宿舍** | 3 層樓、很多窗戶 | 樓梯是天然的瓶頸，床位多 | 窗戶太多，到處都要補 | 影（走廊很暗）、界 |
| **圖書館** | 正門＋地下書庫 | 研究速度加倍（圖鑑、真相碎片） | 容易起火；地下書庫有穿岩蟲 | 憶、光 |
| **游泳池** | 2 個門 | 水是天然的護城河，初期的小蟲過不了水 | 第三夜以後會出現水蟲 | 水、寒 |

每一座據點的入口數量、位置與弱點都不同，所以「選哪裡」本身就是每一輪最重要的決定之一。

## 5. 防線：插槽式建設

### 5.1 入口插槽

每個入口（門、窗、天窗、地板、通風口）都是一個插槽，可以裝一種防禦：

| 防禦 | 效果 | 升級 |
|---|---|---|
| 封板 | 擋住，被打破前蟲進不來 | 木板 → 鐵板 → 鋼門 |
| 拒馬 | 減速，蟲會卡在前面 | 拒馬 → 鐵絲網 → 電網（需要電） |
| 陷阱 | 造成傷害 | 釘板 → 油桶火牆 → 電擊地板 |
| 燈 | 照亮入口，讓你看得到；但會吸引趨光的蟲 | 手電筒 → 探照燈 → 紫外燈 |
| 砲台 | 自動攻擊 | 滅火器砲 → 釘槍砲 → 汽油噴射器 |

### 5.2 設施空地

據點內有約六塊空地，可以蓋：

| 設施 | 效果 |
|---|---|
| 廚房 | 糧食效率提高 |
| 菜園 | 每天生產糧；需要先找到驅蟲草的種子 |
| 發電機 | 每天把油料轉成電 |
| 醫護站 | 倒地的人回到據點會更快復原 |
| 工作台 | 解鎖砲台與高級陷阱 |
| 無線電 | 收到校外的訊息：交易、空投、求救、陷阱 |

### 5.3 每天早上的建設卡

- 每天早上抽三張建設卡，免費選一張；其他的可以花「材」來蓋。
- 建設卡是隨機的，例如「瞭望台」「電網門」「驅蟲草園」「警車警笛誘餌」「消防水帶陣」。
- 這讓據點的長相每一輪都不一樣，也讓玩家每天都有一個小決定。

## 6. 夥伴

### 6.1 招募

- 前夜：用「預言」說服（見 `01` §2.2）。
- 白天：地圖上的紅色求救標記。救回來就是夥伴。

### 6.2 職務

每位夥伴每天做一份工作：

| 職務 | 效果 |
|---|---|
| 守衛 | 夜裡自動防守一個入口 |
| 廚師 | 糧的消耗降低 |
| 農夫 | 菜園的產量提高 |
| 工程 | 夜裡自動修補被打破的防線 |
| 醫護 | 救起倒地的人 |
| 斥候 | 白天自己出去搜刮，晚上回來（有風險，結果寫在生存日誌裡） |

| 夥伴 | 身分 | 特色 |
|---|---|---|

| 方晴 | 健康中心護理師 | 讓醫護站效率加倍 |

## 7. 白天的災害（每天抽一種）

災害會改變規則，**而且會和異能的條件連動**。同一場暴雨，對雷系是福音，對火系是災難。

| 災害 | 規則變化 | 對誰有利 |
|---|---|---|
| 晴 | 無 | — |
| 暴雨 | 視野降低；火焰減弱 | 雷、水 |
| 停電 | 據點沒有電，夜裡全黑 | 影；電機主修的人會很忙 |
| 孢子霧 | 視野極差，待太久會中毒 | 風、生 |
| 酷熱 | 體力消耗加倍，糧食腐壞更快 | 火、寒（保存食物） |
| 斷水 | 糧的消耗加倍 | 水 |
| 低重力潮汐 | 每半分鐘一次低重力 | 重 |
| 赤月（只在後半） | 夜裡的蟲狂暴，異能威力也 ×2 | 所有人，如果你撐得住 |

## 8. 夜晚：每一夜都是新的問題

> 難度提升的方式不是「蟲變多、血變厚」，而是**每一夜都有一種新的威脅**，而且每一種都有世界觀的理由。

### 8.1 七夜結構

| 夜 | 威脅 | 世界觀理由 | 玩家要回答的問題 |
|---|---|---|---|
| 第一夜 | **蝕蝨潮**：大量小蟲 | 裂隙只有針孔大小，只有小蟲過得來 | 防線蓋得夠嗎？ |
| 第二～六夜 | 從下方威脅池抽五種，順序隨機 | — | — |
| 第七夜 | **天裂**：Boss | 裂隙完全打開 | 你們的異能夠強了嗎？ |

### 8.2 威脅池

| 威脅 | 內容 | 世界觀理由 | 對策 |
|---|---|---|---|
| 哨翅夜 | 會飛的蟲從屋頂和窗戶進來 | 牠們找到了你們的燈光 | 封天窗、關燈 |
| 穿岩夜 | 蟲從地板下鑽上來 | 穿岩蟲長大了 | 地板插槽、震動陷阱 |
| 畫皮夜 | 門外有人敲門，叫你的名字 | 擬態蟲學會了人聲 | 小八、問一個只有本人知道的問題 |
| 寄生夜 | 一位夥伴被寄生，半夜在據點裡面變身 | 蛹語者在白天接觸過他 | 醫護站、隔離 |
| **適應夜** | 牠們學會了你最常用的防禦：火變得沒用，或電網被繞開 | 群思在學你 | 換戰術（濕的甲殼會導電，所以改用電） |
| 鐵殼夜 | 大型重甲蟲衝撞正門 | 裂隙擴大到「閘」 | 拒馬、翻倒牠 |
| 頌者夜 | 一隻會讓人產生幻覺的蟲，讓你看見不存在的敵人 | 群思開始干擾你的感官 | 優先擊殺牠 |
| 巢獸夜 | 一隻會走路的巢，持續生出小蟲 | 裂隙擴大到「穹」 | 出去打掉牠背上的巢心 |

### 8.3 Boss（三選一，由蟲族依你的打法選出）

| Boss | 特色 | 解法 |
|---|---|---|
| **千眼之母** | 裂隙的錨。會把被擄走的人當盾牌 | 先救人，再攻擊 |
| **鏡后** | 複製這一輪中玩家發現過的所有異能形態 | 她也繼承了你的弱點。了解自己的異能，才打得贏她 |
| **蛹王** | 被寄生的區隊長，用警察的戰術對付你 | 如果林知夏研究出解藥，可以救回他 |

### 8.4 白天的難度

- **巢苔每天擴散一區**：紅區的蟲更多，物資也更好。
- **資源越來越少**：校園裡的物資箱不會補充，後期一定要遠征到校外。
- **記憶越來越不可靠**（見 `01` §8.2）。

## 9. 蟲族：簡化版

| 蟲 | 出現 | 一句話 |
|---|---|---|
| 蝕蝨 | 第一夜起 | 拇指大，成群湧出 |
| 哨翅 | 白天就會出現 | 偵察兵。被牠看到，當晚會被針對 |
| 拾骸者 | 第一天下午起 | 不攻擊，只會把人拖回繭池。跟著牠能找到巢 |
| 彈刃 | 第二天起 | 跳躍伏擊 |
| 潰液 | 第二天起 | 遠程吐酸 |
| 畫皮 | 威脅池 | 擬態 |
| 鐵殼 | 威脅池 | 坦克 |
| 頌者 | 威脅池 | 干擾、幻覺 |
| 巢獸 | 威脅池 | 移動的巢 |

**弱點**：每種蟲都有一個弱點。解剖之前打不準；林知夏或生科主修的玩家解剖過一隻之後，這一輪所有同種的蟲都會顯示弱點，而且會寫進跨輪的圖鑑。
