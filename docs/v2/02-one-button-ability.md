# v2-02　一鍵異能

## 1. 設計目標

| 目標 | 做法 |
|---|---|
| 極簡 | 只有一顆鍵。按一下釋放，按住蓄力 |
| 不知道自己是什麼 | 開局只看到「？」。第一次按下去，只會出現一點微弱、曖昧的效果 |
| 知識鎖 | 異能有三個**隱藏條件**。在條件成立時按下去，異能就會進化。沒有經驗值，沒有升級選單 |
| 不會卡關 | 按鈕會「發光」：越接近某個條件，光越亮，手把震動越強（冷熱遊戲） |
| 爽 | 每一次發現都是一次威力的跳躍；條件成立時威力 ×3；最後有清場級的覺醒 |
| 和生存連動 | 每個異能至少有一次進化，能幫到據點（發電、種田、保存食物、治療） |

## 2. 結構

```text
異能 = 本源（16 種）
     + 微光（第一次按就看得到的弱效果，暗示本源）
     + 三個隱藏條件 → 三次「頓悟」（永久進化）
     + 共振（條件成立的當下，威力 ×3）
     + 祕密的第四條件 → 覺醒（大招與真名）
     + 過熱（連續使用的風險）
```

**16 種本源**：雷、水、火、寒、風、木、重、影、光、聲、界、心、生、金、數、憶。另有 3% 機率抽到特殊的「空白」。

### 2.1 微光：第一次按下去

- 開局的按鈕上只有「？」。第一次按下去，會出現一個很弱、但看得出性質的效果：一絲電弧、一顆水珠、短暫變透明、地上冒出一根小刺。
- 微光本身就能用（約等於一次普通攻擊），所以按鈕從來不是沒用的。
- 本源要靠玩家自己從微光「看出來」；介面不會寫出名字。

### 2.2 隱藏條件與頓悟

- 每個異能有三個隱藏條件，從約 30 種條件中抽出。
- **在條件成立時按下異能鍵**，就會發生「頓悟」：
  1. 畫面定格 1.5 秒，浮現一句定格句（例如「原來你一直都住在影子裡。」）。
  2. 異能永久進化成新的形態（這一輪內有效）。
  3. 按鈕上的三顆小燈亮起一顆。
- 頓悟之後，即使條件不成立，新形態依然可以使用；**條件成立時則進入「共振」，威力 ×3**。

### 2.3 條件池（約 30 種，分六類）

| 類別 | 條件範例 |
|---|---|
| 環境 | 在水中、在雨中、在黑暗中、在高處、在火旁、站在泥土上、站在巢苔上、碰到金屬 |
| 狀態 | 血量低於 30%、剛衝刺完、靜止三秒、揹著人或重物、被十隻以上的蟲包圍、剛吃飽 |
| 夥伴 | 隊友在三公尺內、和隊友同時按、對著隊友按、背對隊友 |
| 物品 | 拿著金屬棍、拿著水瓶、拿著打火機、拿著手機、拿著擴音器 |
| 地點 | 在廣播室、在菜園、在發電機旁、在鐘樓 |
| 時機 | 蟲攻擊你的瞬間、整點鐘響時、夜晚、停電時 |

**可達性驗證**：生成異能時，三個條件之中至少要有一個在前夜或第一天就能達成，而且三個條件都必須在這一輪的地圖與天氣中可能成立（例如這一輪七天都沒有雨，就不會抽到「在雨中」）。

### 2.4 共鳴光：冷熱遊戲

這是讓知識鎖變得「極簡」的關鍵。

- 異能鍵外圈有一圈光。當你**接近**某一個還沒發現的條件時，光會變亮，手把會輕輕震動。
- 每個條件都有一個「接近度」：
  - 「在水中」→ 離最近的水有多遠
  - 「血量低於 30%」→ 你目前的血量
  - 「被十隻以上的蟲包圍」→ 附近有幾隻蟲
  - 「揹著人」→ 揹著東西時微亮，揹著人時全亮
- 光只告訴你「很接近了」，不告訴你是什麼。玩家要自己想：「我剛剛做了什麼？為什麼它變亮了？」
- **祕密的第四條件不會發光**。它只會在生存日誌裡以一句謎語出現，留給最認真的玩家。

### 2.5 覺醒

- 三次頓悟都完成後，生存日誌會寫下一句關於第四條件的謎語，例如：「雨師只在有人為她哭的時候現身。」
- 達成第四條件並按下異能鍵 → **覺醒**：一段短過場，異能的真名浮現（例如「蒼淵雷獸・夔」），獲得清場級的大招（冷卻很長，大約一夜一次）。

### 2.6 過熱

- 異能鍵沒有冷卻，但連續使用會累積「過熱」。
- 過熱滿了會「暴走」三秒：威力極大，但會往四面八方亂射，傷到身邊的隊友。
- 這是唯一的代價規則。玩家會自然學會：「快滿的時候，先衝進蟲群中央再暴走。」

## 3. 範例異能（10 種）

> 格式：微光 ／ 三個條件與頓悟 ／ 覺醒。每個異能都標出它幫助生存的那一次進化（★）。

### ① 逆雷（雷）
- **微光**：一道小電弧，打最近的一隻蟲。
- **碰到金屬** → 導雷：被你碰過的門把、欄杆、鐵捲門會變成電擊陷阱。
- **在雨中** → 連鎖閃電：一次打十隻。
- ★ **在發電機旁** → 充電：據點的「電」直接加滿。
- **覺醒**（剛衝刺完、心跳最快時）→ 蒼淵雷獸「夔」：雷暴領域。

### ② 懸雨（水）
- **微光**：一顆水珠彈。
- **在雨中或水邊** → 懸停：周圍的雨滴停在半空，蟲穿過時會被減速。
- **靜止三秒** → 水彈陣：懸停的雨滴一起射出去。
- ★ **拿著水瓶** → 淨水：據點的斷水災害無效。
- **覺醒**（血量低於 10% 時）→「雨師」：你的血也停在半空，化為回復的水盾。

### ③ 影步（影）
- **微光**：身體變半透明一秒，蟲會短暫找不到你。
- **在黑暗中** → 影中瞬移：從一片陰影跳到另一片陰影。
- **觸碰隊友** → 同行：把隊友一起帶進陰影。
- ★ **停電時** → 夜行：停電之夜，整個據點的陰影都是你的通道，夥伴也不會因為黑暗而恐慌。
- **覺醒**（站在隊友的影子裡）→「夜行狸」：所有影子都是門。

### ④ 墜星（重）
- **微光**：把身邊的蟲推開一點。
- **在高處** → 衝擊坑：從高處跳下時按，落地形成衝擊波。
- **揹著人或重物** → 雙人大跳：揹著隊友一起跳上屋頂。
- ★ **揹著重物** → 輕量化：一個人就能搬發電機和冰箱。
- **覺醒**（被二十隻以上包圍）→「負嶽」：重力井，把整波蟲吸到一點。

### ⑤ 熔掌（火）
- **微光**：手掌發燙的一記近身攻擊。
- **拿著金屬棍** → 燒紅的武器：近戰傷害大增。
- **在火旁** → 火焰噴射。
- ★ **剛吃飽** → 灶火：據點的廚房效率加倍（「吃飽了才有力氣煮飯」）。
- **覺醒**（夜晚，站在據點正門）→「畢方」：火鳥繞著據點飛一整夜。

### ⑥ 荊棘（木）
- **微光**：地上冒出一根小刺。
- **站在泥土上** → 荊棘牆：一整面擋路的刺牆。
- **血量低於 30%** → 吸血荊棘：荊棘刺中的蟲會為你回血。
- ★ **在菜園** → 催熟：作物當場成熟，據點的「糧」大增。
- **覺醒**（拿著從後山帶回來的種子）→「建木之芽」：一棵巨樹，成為第二座據點。

### ⑦ 哨令（聲）
- **微光**：一聲尖嘯，讓最近的幾隻蟲暈眩半秒。
- **拿著擴音器** → 音爆：範圍擴大三倍，還能把蟲群引到你指定的方向。
- **背對隊友** → 回聲：全隊共享周圍的視野（看穿牆壁）。
- ★ **在廣播室** → 召集：全校廣播，下一個白天會有更多倖存者主動來據點投靠。
- **覺醒**（整點鐘響時）→「鵸鵌」：一首歌，讓全場的蟲停下五秒。

### ⑧ 對調（界）
- **微光**：和身邊最近的箱子交換位置。
- **對著隊友按** → 救援換位：和遠處的隊友交換位置（最強的救人技）。
- **蟲攻擊你的瞬間** → 換蟲：和攻擊你的蟲交換位置，讓牠撞上自己的同伴。
- ★ **揹著東西** → 傳送：把背包裡的物資直接送回據點。
- **覺醒**（和隊友同時按）→「雙生狐」：全隊一起瞬移。

### ⑨ 擲幣（數，稀有）
- **微光**：擲出一枚光幣。正面：下一擊暴擊；反面：預見下一波蟲從哪裡來。
- **拿著手機** → 讀運：連續三次正面時，下一個物資箱必出異化物品。
- **靜止三秒** → 選面：可以自己決定正反，但過熱加倍。
- ★ **整點鐘響時** → 好運：當天所有物資箱多一件東西。
- **覺醒**（連續七次正面）→「命骰龜」：一輪只能用一次，讓一位剛死去的夥伴「其實只是昏迷」。

### ⑩ 空白（無，特殊 3%）
- 按鈕上永遠是「？」，按下去什麼也沒有。
- 但你免疫所有擬態與寄生，畫皮蟲騙不了你；群思把你當成「不存在」。
- 祕密的條件：你是唯一能走進母巢核心而不被同化的人。
- 結算時的異能揭曉：「你什麼都沒有。所以牠們什麼都拿不走。」

## 4. 共鳴：兩個人一起按

- 兩位玩家在 5 公尺內、1 秒內先後按下異能鍵，就會依照兩人的本源觸發共鳴。
- 規則只有一條，連鍵表都不用背：**兩種本源相遇，會產生一個名字很合理的結果。**

| 組合 | 共鳴 | 效果 |
|---|---|---|
| 雷 ＋ 水 | 雷雨陣 | 一整片帶電的懸停雨滴 |
| 火 ＋ 風 | 火旋 | 會移動的火龍捲 |
| 火 ＋ 木 | 火荊 | 燃燒的荊棘牆 |
| 重 ＋ 界 | 流星換位 | 把隊友換到高處，讓他砸下來 |
| 聲 ＋ 心 | 群思竊聽 | 聽見下一波從哪裡來 |
| 光 ＋ 影 | 日蝕 | 一塊所有蟲都看不見的黑暗 |
| 水 ＋ 寒 | 冰橋 | 跨越巢苔或水面的冰路 |
| 生 ＋ 任何 | 護航 | 被共鳴的隊友回滿血 |

## 5. 夥伴的異能

- 救回來的 NPC（警校生、志工、教職員）也有自己的隱藏異能，規則和玩家一樣。
- 夥伴身上也有共鳴光。把他帶到條件附近，他頭上的光會變亮；讓他在那裡出手，他就會頓悟。
- 頓悟過的夥伴會在夜裡變成很強的守衛。這讓「救人」和「探索異能」變成同一件事。

## 6. 異化物品：每個箱子都是驚喜

交融波之後，撿到的物品有機會帶著 0–2 條**異化詞綴**：

| 詞綴 | 效果 |
|---|---|
| 回力 | 丟出去會自己飛回來 |
| 永電 | 不用充電 |
| 餓鬼 | 吃東西時攻擊力提升 |
| 通靈 | 靠近蟲時會發出聲音 |
| 共鳴 | 拿著它時，你的共鳴光範圍加倍 |
| 沉睡 | 晚上拿著它，蟲比較不會注意到你 |
| 認主 | 只有撿到的人能用，但威力加倍 |
| 記憶 | 重生之後，它會出現在下一輪的某個地方 |

詞綴的效果**不會寫在物品說明上**，只寫「這把雨傘有點奇怪」。要用了才知道。這是物品版本的知識鎖。

## 7. 異變的動植物

| 對象 | 異變 | 用途 |
|---|---|---|
| 警犬小八 | 嗅覺增強 | 夥伴：嗅出擬態蟲，夜裡會先叫 |
| 校園流浪狗 | 變大，有領地意識 | 餵食後成為據點的巡邏犬 |
| 烏鴉 | 會模仿人聲 | 會說出牠聽過的話（線索，或者驚嚇） |
| 鏡湖錦鯉 | 發光 | 不會吸引蟲的冷光源 |
| 驅蟲草（異界混種） | 煙燻可以驅蟲 | 種在菜園，夜裡點燃 |
| 食蟲花 | 巨大化 | 種在門口，會吃小蟲 |
