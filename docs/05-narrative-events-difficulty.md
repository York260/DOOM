# 05　敘事、事件與難度

## 1. 敘事設計原則

1. **骨與磚**：主線的「骨架」是手工設計的（五幕結構、必然節點、角色弧線）；「磚」是系統生成的（事件池、隨機變數、玩家行為）。骨架保證每一局都有起承轉合，磚保證每一局都不一樣。
2. **戲劇來自系統，而不是過場**：最動人的時刻應該是「因為我剛剛做了那件事，所以他才……」，而不是一段我們預先寫好的動畫。
3. **小說感的五個工具**：章回標題、定格句、營火夜話、無線電劇場、結算報告。
4. **人是核心**：蟲是壓力，人是故事。每一個 NPC 都要有一個「如果他死了，玩家會記得的理由」。

## 2. 命運織機：敘事導演

### 2.1 職責

| 職責 | 說明 |
|---|---|
| 張力管理 | 監控玩家的生命、壓力、彈藥、損失與近期戰鬥強度，控制「醞釀 → 高峰 → 喘息」的節奏（類似《Left 4 Dead》的 AI Director） |
| 事件調度 | 從事件池中依照前置條件、權重與冷卻挑選事件 |
| 異能保底 | 執行提示階梯（見 `02` §6.2），安排能自然觸發鑰匙的情境 |
| 戲劇機會 | 偵測「戲劇鉤子」並打開對應的選項（見 §2.3） |
| 群思協調 | 和群思 AI 協商下一波的規模與時機，避免連續高壓導致挫折 |
| 記錄 | 把事件寫入事蹟記錄器，並標記戲劇權重 |

### 2.2 三位說書人

| 說書人 | 風格 | 張力曲線 | 特色 |
|---|---|---|---|
| **史官** | 平衡、紀實 | 穩定的波浪 | 預設。旁白冷靜，像紀錄片 |
| **說書人** | 戲劇化、大起大落 | 劇烈的高峰與深谷 | 更多定格句、更多犧牲機會、更多絕處逢生 |
| **判官** | 嚴苛、因果報應 | 依玩家的選擇而定 | 你拋棄的人會回來找你；你救過的人會在關鍵時刻還你。「品格」評分加倍計算 |

### 2.3 戲劇鉤子（由導演偵測並觸發）

| 鉤子 | 偵測條件 | 導演的動作 |
|---|---|---|
| **最後一班哨** | 一位高好感 NPC 在據點，防線即將崩潰 | 給 NPC「留下斷後」的選項，玩家可以接受或阻止 |
| **重逢** | 分頭行動的玩家或 NPC 在失散一段時間後再次相遇 | 播放重逢音樂與定格句 |
| **遲來的救援** | 有人被擄走、倒數即將結束，玩家正在趕路 | 給一次「剛好趕上」的機會（但不是每次都成功） |
| **托付** | 一位 NPC 臨終，身邊有玩家 | NPC 把遺物（或天賦轉移）交給玩家 |
| **危難覺醒** | 隊友或 NPC 陷入危險，玩家的極鑰與「關係」或「情緒」有關 | 讓極鑰的觸發條件更容易出現 |
| **反轉** | 某人是擬態蟲或被寄生 | 選在最有衝擊力的時刻揭露（例如在他要為你包紮的時候） |
| **點名** | 晚點名時有人缺席 | 點名表停頓一秒，NPC 念出名字，無人回應 |
| **餘燼** | 局勢大好，玩家開始輕敵 | 製造一次合理的意外，例如鐘聲讓異能失效 |

### 2.4 章回標題與定格句

**章回標題**由「事件意象」生成：`第{N}章　{意象}`。

範例：
- 第一章　熄燈號沒有響的第三天
- 第二章　門把上的雷
- 第三章　關上的那扇門
- 第四章　雨停在半空
- 第五章　她說她沒被咬
- 第六章　最後一班哨
- 第七章　牠們學會了閉眼
- 第八章　池底的門
- 第九章　十二個名字，九個回答
- 終章　七十二小時後的早晨

**定格句**範例（關鍵瞬間，畫面放慢，浮現一行）：
- 那一秒，許安第一次沒有閉上眼睛。
- 雨停了。不是因為天晴，是因為你屏住了呼吸。
- 你終於知道，為什麼這所學校的人一天要敬禮一百次。
- 門外的聲音在叫你的名字。是他的聲音。不是他。
- 點名簿上，陳硯的名字淡了一點。
- 牠們在學你。
- 小八沒有叫。牠只是擋在你前面。
- 你什麼都沒有。所以牠們什麼都拿不走。

### 2.5 營火夜話

- 喘息期中，可以和 NPC 坐下來聊天。話題包括家人、為什麼念警校、害怕什麼、昨晚夢到什麼。
- 效果：提升關係、解鎖**遺言**、取得異能線索（「你知道嗎，你睡覺的時候，手在發光」）、取得真相層碎片（黃伯講古）。
- 營火夜話是本作最重要的「張弛」中的「弛」，也是讓玩家在 NPC 死去時真正心痛的準備。

### 2.6 無線電劇場

- 派遣中的 NPC、遠方的分局、軍方、陌生人的求救，都透過無線電即時演出。
- 玩家只聽得到聲音，必須用想像力補完畫面，這往往比畫面本身更有力量。
- 範例：「七號呼叫據點……我們拿到藥了，正在回去……等一下，你們有聽到嗎？那是……豆漿，不要回頭，跑！跑——」（雜訊）

| 幕 | 名稱 | 遊戲內時間 | 實際時間 | 主題 | 必然節點 | 可變節點（範例） |
|---|---|---|---|---|---|---|

| 第三幕 | **巢化** | D2 06:00–D3 06:00（H22–H46） | 約 40 分鐘（含睡眠快轉） | 擴張與猜忌 | 第一次遠征雲台鎮、第一次寄生事件 | 派系衝突、異獸過境、黃金七十二小時 |

| 終幕 | **天裂** | D4 00:00–07:42（H64–H72） | 約 30 分鐘（含 Boss） | 逃、守，還是結束它 | Boss 戰、結局抉擇 | Boss 種類、誰還活著 |

## 4. 每一局都是平行時空：種子變數

### 4.1 開局變異日

| 開局日 | 機率 | 變化 | 戲劇核心 |
|---|---|---|---|
| 平日 | 30% | 標準 | — |
| **全校防災演習日** | 10% | 交融波的警報被所有人當成演習。拒馬、擔架、廣播都已就位，但 NPC 反應延遲 | 「這不是演習。」 |
| 期末考週 | 10% | 全員都在教室；考卷是異化物；壓力起始值較高 | — |
| 校慶日 | 10% | 校園中有大量家屬與民眾（老人、小孩），園遊會攤位、舞台 | 更多需要保護的人 |
| 颱風夜 | 10% | 交融波發生在 21:00；全程大雨（水、雷系異能的天堂）；多數學生已回家，校園幾乎空無一人 | 孤獨 |
| 新生報到日 | 10% | 新生不認識校園，家長在場，許安剛報到 | 「學長，這裡哪裡安全？」 |
| 畢業典禮前夜 | 10% | 四年級在宿舍開告別派對；陳硯的最後一晚 | 離別 |
| 停電檢修日 | 5% | 一開始就沒有電 | 黑暗 |
| 連假收假日 | 5% | 一半的人還沒回來 | 等待 |

### 4.2 世界線參數

| 參數 | 變化 |
|---|---|
| 天氣軌 | 72 小時的天氣序列（晴、雨、雷雨、濃霧、孢子霧、赤月） |
| 主裂隙位置 | 五個候選：田徑場上空、鏡湖、圖書館地下、後山防空洞、化工廠 |
| 次裂隙 | 2–4 個 |
| NPC 命運 | 每位 NPC 的覺醒與否、異能、命運傾向（不是固定劇本，而是權重） |
| 七大不可思議 | 啟動其中 3–5 個 |
| Boss 候選 | 兩位候選，由群思最終決定 |
| 說書人 | 玩家選擇或隨機 |
| 誰停掉了熄燈號 | 白教授／區隊長／小蟬／某位玩家的 NPC 室友／無人（排程自己壞了） |

### 4.3 世界線變異（模組，稀有或可選）

- 低重力時間線：重力只有 80%
- 永夜時間線：第二天之後太陽不再升起
- 空庫時間線：械彈庫是空的，有人比你們先到了（誰？）
- 全員覺醒：沒有常人
- 唯一覺醒：只有玩家覺醒，NPC 全是常人
- 鏡像校園：整張地圖左右翻轉（老手的地圖記憶失效）
- 「這條時間線的你，已經死過一次」：你的鬼魂會在序章中為你引路，但它也記不得自己是怎麼死的

## 5. 事件池（Storylets）

### 5.1 事件格式

```yaml

名稱: 門外的人
類型: 抉擇
幕: [第二幕, 第三幕]
前置: { 時段: 夜, 據點: 已建立, 畫皮: 已解鎖 }

參與者槽位:
  - 門外者: { 條件: 失聯中的 NPC 或隨機倖存者 }
內容:
  - 敲門聲，門外的人叫出某位玩家的名字
分支:
  - 開門: { 若為真人: 救援+1；若為畫皮: 據點被突破 }
  - 查驗: { 需要國境系或小八；耗時，期間防線壓力上升 }

後果旗標: [door_choice_made]

```

## 6. 抉擇設計

> 原則：**沒有正確答案**。後果會**延遲**出現。判官說書人會放大後果。

| 抉擇 | 選項 | 即時後果 | 延遲後果 |
|---|---|---|---|
| 門外的人 | 開門／查驗／不開 | 救人或被突破 | 不開而門外是真人 → 創傷、倖存者評價 |
| 全校廣播 | 召集／沉默／報告真相 | 人多了，蟲也多了 | 被召集來的人之中，有人會在第三幕背叛（或救你一命） |
| 槍給誰 | 遵守區隊長「學生不持槍」／違抗 | 火力 vs 秩序 | 教官派的信任；有人誤傷 |
| 她說她沒被咬 | 相信／隔離觀察／處決 | — | 相信：30 分鐘後可能爆發；隔離：她的信任下降；處決：若她其實沒事，全據點士氣崩潰 |
| 異獸過境 | 庇護／誘餌／關門 | 庇護會引來追兵 | 庇護 → 霧鹿之後在濃霧中引路；誘餌 → 白澤拒絕見你 |
| 化工廠 | 炸／不炸 | 消滅鎮上的巢 | 老街的倖存者會記得是誰做的決定 |
| 撤離名單 | 誰上飛機？名額比人數少 | — | 留下的人的評價；你自己要不要走？ |
| 救一個還是救一群 | 同一時間：一位被擄走的好友在繭池，十五位民眾在醫院 | 只能選一邊（或者分頭行動，兩邊都可能失敗） | 多人模式下，隊伍可能因此分裂 |

## 8. 難度：分階段，而且多元

### 8.1 原則

> **每一個階段改變的是「問題」，而不只是數字。**

- 難度提升有世界觀上的理由（裂隙口徑、疊合率、群思學習、人心崩壞）。
- 每個階段打開**新的壓力軸**，而不是把舊的調高。
- 玩家可以**影響**難度的速度（減少生物量、拖慢裂隙擴張、誤導群思）。
- 每一個高峰之後，一定有喘息。

### 8.2 十軸壓力

| 軸 | 內容 | 世界觀來源 |
|---|---|---|
| **量** | 蟲的數量 | 生物量 |
| **質** | 兵種的種類與體型 | 裂隙口徑 |
| **智** | 蟲的戰術與演化 | 群思學習 |
| **地** | 地形的敵意（巢苔、坍塌、異界植物） | 巢化 |
| **天** | 天候與物理規則（黑夜、孢子霧、赤月、重力潮汐） | 疊合率 |
| **物** | 資源稀缺（彈藥、食物、乾淨的水、電力、藥品） | 文明崩潰 |
| **人** | 人心（恐慌、派系、暴民、背叛） | 社會崩潰 |
| **己** | 自身（異能代價升級、異化、創傷、疲勞） | 疊合加深 |
| **時** | 時間壓力（撤離窗口、倒數、寄生卵） | 劇情 |
| **知** | 資訊（無線電干擾、擬態、假訊息、記憶代價） | 頌者與畫皮 |

### 8.3 階段表

| 階段 | 開啟的壓力軸 | 世界觀理由 | 玩家要回答的新問題 |
|---|---|---|---|
| 序章　日常 | 知（錯過異兆的代價） | 疊界尚未發生 | 「我有注意到什麼嗎？」 |
| 第一幕　裂隙初開 | **人**（恐慌、失控覺醒者）、物（槍被鎖起來）、量（低） | 口徑 I，只有小蟲；最大的威脅反而是剛覺醒、無法控制力量的人 | 「怎麼在混亂中組織起來？」 |
| 第二幕　第一夜 | **天**（黑夜、停電）、**智**（試探）、質（口徑 II） | 蟲的母世界是黑暗的；群思開始收集情報 | 「怎麼在黑暗中守住？」 |
| 第三幕　巢化 | **地**（巢苔）、**物**（水源被異化藻類污染、食物短缺）、**知**（擬態、寄生）、**人**（派系） | 蟲開始建立後勤；人類的壓力到達臨界點 | 「我們之中誰是假的？資源夠撐嗎？」 |
| 第四幕　適應 | **智**（大規模適應）、**天**（異界天候、物理改變）、**己**（代價升級、異化）、質（口徑 III–IV） | 群思學會了你；兩個世界加速融合 | 「我們慣用的方法失效了，現在怎麼辦？」 |
| 終幕　天裂 | **時**（撤離窗口、裂隙崩塌倒數）、量（最大）、Boss | 口徑 V | 「要逃、要守，還是要結束它？」 |

### 8.5 難度設定

| 難度 | 名稱 | 說明 |
|---|---|---|
| 1 | 新生 | 提示強度預設為「輔助」、群思適應減緩、彈藥較多 |
| 2 | 學員 | 標準 |
| 3 | 警佐 | 群思適應加快、資源減少 |
| 4 | 警正 | 擬態與寄生更頻繁、判官說書人的因果放大 |
| 5 | 特勤 | 沒有提示階梯的第三階、死亡後只能接續一次 |
